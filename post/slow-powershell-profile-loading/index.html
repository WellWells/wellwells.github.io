加快 PowerShell 設定載入速度的方法

PowerShell 開啟要花兩秒，問題出在防毒軟體掃描腳本。記錄怎麼確認是 Profile 造成的、哪些模組路徑要加進 Bitdefender 例外清單，以及 posh-git 為什麼加了也沒用。

前言

安裝 PowerShell 後，通常還會再裝一些擴充功能，例如：

  1. PSFzf：模糊搜尋。
  2. zoxide：快速導向檔案系統。
  3. posh-git：Git 命令提示和自動完成。
  4. Oh My Posh：強化 PowerShell 提示樣式。
  5. 等...

這些外掛程式可以按照各自的安裝方式整合到 PowerShell。

但裝著裝著就會拖慢載入，每次開啟 PowerShell 都要等上一段時間。

本篇文章將說明並記錄我的解決過程。

確定問題

首先在 PowerShell 中，輸入以下命令以編輯 PowerShell 的使用者設定檔（Profile）：

1
2

# 沒有安裝 VS Code，請使用 notepad。
code $PROFILE

可以看到目前的安裝與設定如下，分別載入 PSFzf 與 zoxide 兩個模組。

1
2
3
4
5
6

Set-PsFzfOption -PSReadlineChordProvider 'Ctrl+t' -PSReadlineChordReverseHistory 'Ctrl+r'
Set-PSReadLineKeyHandler -Key Tab -ScriptBlock { Invoke-FzfTabCompletion }

Invoke-Expression (& { (zoxide init powershell | Out-String) })

function grep { $input | out-string -stream | select-string $args }

當開啟 PowerShell，可以看到載入時間約 2000 毫秒。用 pwsh --noProfile 暫時跳過 Profile 檔案的載入，就能判斷是不是載入設定檔造成的。

1
2
3
4
5

PowerShell 7.4.3
Loading personal and system profiles took 2074ms.

PS C:\Users\Wells> pwsh --noProfile
PS C:\Users\Wells>

會發現載入的時間變快了。表示由於載入設定檔所導致。

參考 PowerShell 官方的 Issue，會發現有人也有類似情況發生，其中關閉防毒軟體後，載入速度就正常了。

防毒軟體的影響

我使用的防毒軟體為 Bitdefender，它有 掃描惡意指令碼（Scan scripts） 這個功能。關閉這個功能後，載入速度恢復正常。我也把整個 Bitdefender 的防禦功能（Bitdefender Shield）關掉測試，載入速度同樣有改善。

解決方法

把信任的腳本位置加入例外清單就行。首先，用 Everything 工具搜尋關鍵字（如 psfzf 或 zoxide），可以找到以下路徑：

1
2

c:\users\<user>\documents\powershell\modules
c:\users\<user>\appdata\local\microsoft\winget\packages\ajeetdsouza.zoxide_microsoft.winget.source_8wekyb3d8bbwe

將這些路徑加入 Bitdefender 的例外清單後，每次開啟新的 PowerShell 視窗，載入速度應在 500 毫秒以內。

不過像 posh-git 這類模組，本身載入速度就很慢，關掉防毒軟體也一樣，加進例外清單自然也沒用。
