引言

這篇文章會介紹我在 Windows 上常用到的開發工具，並說明為什麼要安裝以及好用在哪。

在 Windows 上開發，除了內建的記事本、小畫家、命令提示字元（cmd）之外，換上別的工具會有效率很多。

雖然主要著重於 Windows 開發過程中的工具，但其中一些技巧也可應用在 Linux 環境中。

隨時準備好左手。左手在快速完成某些事情時是很重要的，大多數的情況下負責的是快速鍵的呼叫。

快速鍵

Windows 上的快速鍵很多，基本的有：

  • ⊞ Win + R：開啟執行視窗（可用 PowerToys Run 或 Everything 取代）

    輸入 cmd、calc（小算盤）、notepad（記事本）、regedit（登錄編輯程式）、mstsc（遠端桌面連線）、mspaint（小畫家）可快速開啟相對應的應用程式。

  • ⊞ Win + D：快速回到桌面，再一次會還原全部視窗

  • ⊞ Win + Shift + S：自由截圖 （可用 ShareX 取代）

    Alt + Print Screen：視窗截圖

  • ⊞ Win + L ：鎖定電腦不登出

  • ⊞ Win + ; ：Emoji 面板打表情符號（分號鍵位於英文字母 L 的右邊）

  • Ctrl + Shift + Esc：直接開啟工作管理員，對比於Ctrl + Alt + Del只需要左手就可以完成，而且也不用先叫出 menu 後，再用滑鼠點工作管理員。

部分像是 Emoji 面板為 Windows 10 以上內建，其他快速鍵大多數在 XP 時代就存在了。

另外像是 Ctrl + X / V / Z / F / S / A 為標準指令，對應 剪下、貼上、復原輸入、搜尋、儲存、全選，大多古老的 Ctrl 指令就不再此贅述。

安裝 winget

Windows 程式套件管理器（winget）是微軟為 Windows 10 及 Windows 11 推出的應用程式，可以搜尋、安裝、移除、更新所需軟體。

有了 winget 就能用統一的方式快速安裝軟體，避免多餘的行為（尋找軟體的官方網站→找到下載連結→下載→執行→安裝→刪除安裝檔）

若要檢查系統是否支援，可以打開命令列（鍵盤上的 ⊞ Win + R，並輸入 cmd 後點確定），輸入以下指令：

1

winget --version

回傳結果為版本 v1.28.220：

1
2

C:\Users\wells>winget --version
v1.28.220

倘若找不到版本表示尚未安裝，可以到 Microsoft Store 安裝 winget。

安裝後，記得重新啟動 cmd 再檢查版本，如果安裝成功，就可以看到版本號。

推薦軟體

以下介紹哪些軟體可以幫忙快速完成任務，順序依名稱排序。

Everything

基於 C 語言的 Windows 桌面搜尋引擎，可以在 NTFS 磁碟中快速搜尋檔案名稱或內文。

基本上是可以取代 Windows 內建的檔案搜尋功能作為日常使用，其最大特點是即時的檔案搜尋。

工作原理是對電腦上所有的檔案與資料夾從主要檔案資料表（master file table，MFT）建立資料庫索引，在打開 Everything 時，資料庫會載入到記憶體裡做即時搜尋，並在背景追蹤 Windows 中的 Update Sequence Number 日誌（USN Journal）持續更新資料庫。

Everything 可透過 winget 於 cmd 中完成安裝，或是官網自行下載。

1

winget install -e --id voidtools.Everything

安裝過程由於要存取 USN 日誌，所以會需要系統管理員權限。這邊採預設安裝為服務，日後開機自動在背景執行。

安裝後，第一次打開會對電腦建立索引，索引後便可以開始搜尋檔案。

預設空格為 and 運算，所以要找檔名有 ABC 的 png 圖片可以搜尋：ABC .png

若要搜尋檔名有 abc，且副檔名為 png 或是 txt 可以搜尋：abc .png|.txt

在搜尋上可以用正規表示式語法做更複雜的搜尋。

更多的規則可以參考說明 → 搜尋語法。裡面也有說明如何搜尋檔案內容。

你可以到設定頁面設定快速鍵。我個人喜歡用 Alt + X 快速喚出 Everything 視窗，當然也可以根據個人需求自訂快速鍵設定。

另外也可以手動指定伺服器上的資料夾路徑給 Everything 索引。

Git

當我尚未接觸到 Git 時（年幼時期），定時備份程式碼的方式是把所有檔案壓縮起來，然後加上時間標記。這種方式效率低，也無法追蹤歷史紀錄。甚至過了幾個月，單靠檔案名稱也根本不知道改了什麼。

Git 是一個免費的開源分散式版本控制系統，使用 Git 來管理檔案，能夠記錄檔案間的差異，也能回溯歷史版本或整合，快速可靠地追蹤檔案狀態。

操作 Git 可以很簡單也可以很複雜。大部分的情況不外乎就是提交（commit）與合併（merge）的行為，最終的目的是確保檔案能夠準確被記錄、程式能夠正常工作。

Git 可透過 winget 於 cmd 中完成安裝。

1

winget install --id Git.Git -e --source winget

想要確定電腦是否成功安裝 Git，開啟 cmd 並輸入：

1

git --version

回傳結果版本號為 2.53.0.windows.2：

1
2

C:\Users\wells>git --version
git version 2.53.0.windows.2

後續更詳細的 git 操作，後續有機會再開新的議題討論與分享。

Notion

Notion 是一款多功能的筆記軟體，對於一般使用者來說基本上免費就很夠用了。我覺得他能夠快速、井然有序地建立表格、貼圖、多欄位等功能，就勝過很多筆記軟體了。並且還能夠直接分享筆記書出為公開網址、轉存為 PDF 或是 Markdown。

先前我整理筆記的方式是開 Word 搭配 Microsoft 365 的雲端同步，但 Word 基本為制式格式，並且鎖在 A4 等標準紙張，常常有像表格過長超過一頁，或是要靈活的在一個頁面分多欄，在 Word 上要用分節或表格 + 隱藏框線等技巧，很麻煩。

反之，Notion 這些問題都解決了。Notion 免費版已提供 7 天的頁面歷史紀錄回溯，對於個人用戶來說很夠用。

我有試著用 Microsoft OneNote 寫筆記，但邏輯上沒辦法接受。

一個筆記檔案，赤裸裸的儲存在 OneDrive 上，檔案可任意移動。

筆記本打開後，分了節與頁面，筆記的部分可以任意排位置，與 iOS 的無邊記類似。基本上是沒有順序的邏輯。

與 Notion 相互匹敵的有像是微軟的 Loop，它已在 2023 年 11 月正式發布，不再是 Beta 版本，並且與 Microsoft 365（如 Teams、Outlook）有著更深度的整合。

微軟最大的優勢在於一推出就有繁體中文，相較於 Notion 對於繁體中文的支援程度非常差。

不過 Loop 在 iOS 端我個人的體驗沒有很好，目前可能還要等待微軟的最佳化吧。

安裝方式可以透過 winget 於 cmd 中完成安裝：

1

winget install -e --id Notion.Notion

安裝後，在 Notion 註冊完就可以開始寫了。手機與電腦版的體驗一致性蠻高的。

Powershell 7

在 Windows 系統中，除了內建的命令提示字元（cmd），其實還內建了 Powershell，只不過內建的版本是 PowerShell 5.1，並基於 .NET Framework，於執行中輸入 powershell 便可開啟。

而 Powershell 7 是基於 .NET Core，跨平台做得更好，可透過執行輸入 pwsh 開啟，除了支援新的指令（Cmdlet），也支援跨平台與新的模組的擴充與安裝，還有自動完成打過的指令（cmd 要靠 clink 才做得到）。為微軟目前積極更新的軟體之一，也建議每個開發者裝一下。

Powershell 7 可透過 winget 於 cmd 中完成安裝，亦可參照其他方式

1

winget install --id Microsoft.Powershell --source winget

PowerToys

微軟開發的公用程式，裡面包含許多工具，工具都是綑綁在 PowerToys 裡面。

以下列出我覺得蠻常用的工具：

工具名說明
Always on Top用快速鍵 (⊞ Win + Ctrl + T) 把視窗釘在其他視窗上面。
PowerToys Awake可以讓電腦保持永遠喚醒狀態。
色彩選擇器是一種全系統的色彩挑選公用程式。
FancyZones視窗管理器，可以快速建立複雜的視窗版面設定。
File Explorer 附加元件可在 File Explorer 中啟用預覽窗格和縮圖轉譯。
圖像大小調整器對著圖片右鍵就可快速調整影像大小。
尋找我的滑鼠按鍵盤左 Ctrl 兩下可以快速定位滑鼠位置。
無框線的滑鼠用同一組鍵盤和滑鼠操作多台電腦。
PowerToys Run立即搜尋並啟動應用程式。
文字擷取器對圖片做 OCR 辨識並抓出文字。

各個工具的介紹可以參考微軟 PowerToys 官方說明，寫得很清楚，並且在安裝後也會有 intro 介紹各個功能該如何使用。

PowerToys 可透過 winget 於 cmd 中完成安裝。

1

winget install Microsoft.PowerToys --source winget

原本是用 ⊞ Win + R 叫出執行視窗，如果輸入錯誤會無法正確啟動程式。

安裝好後，PowerToys 內建 PowerToys Run，可透過鍵盤上的 Alt + Space喚醒 Run 視窗，並支援模糊搜尋、中文輸入甚至是簡易計算。

當然裡面還有一些工具像是抓取顏色（ColorPicker），適合用於網頁開發，快速鍵為⊞ Win + Shift + C

或是對圖片做 OCR 辨識並擷取文字，快速鍵為⊞ Win + Shift + T

PowerToys 與 Windows 整合性很高，平常感受不到它的存在，卻又補上很重要的功能。

ShareX

開源的截圖、錄製軟體，可以錄製 mp4 或是 gif 動圖，並整合上傳功能、OCR 或是上浮水印等其他效果，也支援內建編輯器，功能多但又輕巧。

安裝方式可以到 GitHub 下載，或透過 winget：

1

winget install -e --id ShareX.ShareX

安裝後，右下角會有 ShareX 圖示，可以設定語言、快速鍵、截圖後要做什麼（開啟資料夾、上傳、列印等...）等一系列操作。

本軟體是支援繁體中文的，但預設語言是英文。

對著圖示右鍵，找到應用程式設定（Application Settings） → 一般（General）可以找到語言（Language），把 Automatic 改為繁體中文即可。

後續使用上應該沒有太多困難。比較龜毛的可以在任務設定 → 擷取底下有一個擷取視窗透明度可以打開，針對 Windows 11 的圓角邊框會處理好而不會有背景色。

Tailscale

Tailscale 可以讓裝置在不曝露於外網的情況下互相存取，很快就能架起個人 VPN，並用多種方式穿透防火牆。

使用者不需要了解其中原理，僅需要將多個裝置登入至 tailnet，裝置之間就能互通。

像是可以做到以下情境：

  1. A 電腦存取 B 電腦的資源，如網路芳鄰共享(Samba)、或是 NAS 資源。
  2. 點對點的連線，像是 SSH、遠端桌面連線。
  3. 子網 subnet 路由。例如內網 IP 位址：192.168.6.XX。手機可以在不同網路上用同個 IP 位址連線。
  4. 流量代理。可以指定裝置的流量，經由另一個節點出口。
  5. 公網直連。用 Funnel 讓公網可以直接存取該裝置。
  6. 點對點傳檔。
  7. 等....

更多的參數與設定，可以參考使用 Tailscale 輕鬆建立安全且私密的隧道。

Visual Studio Code

微軟開發的跨平台編輯器，擴充性很強，對於開發者而言，Visual Studio Code（VS Code）是必備的。

基本上裝了 VS Code，其他軟體像是 notepad++、Eclipse，可以有條件式的直接取代。

VS Code 特性包括：

  • Intellisense 程式碼完成
  • Git 版本控制
  • 並支援多語言突顯和語法檢查，例如 JavaScript、TypeScript、Python、C++ 等。
  • 跨平台支援（Windows、macOS、Linux）。
  • 內建程式碼格式化、重構、偵錯等功能。
  • 支援使用 tasks.json 定義任務，如編譯、執行等。
  • 豐富的擴充功能生態系統（不支援的語法？裝個擴充就解決了！）
  • SSH 遠端開發，並支援連接埠轉發（Port Forwarding）。
  • 搭配 WSL 在 Windows 下做 Linux 開發
  • 多樣的主題可以自由更改。

內容主題繁多，也需要花一些時間學習，但就初學者而言，也是可以當作一般的文字編輯器。

後續如果有機會再來說說 VS Code 的一些操作方式。

安裝方式可以到 微軟官網下載，或透過 winget：

1

winget install Microsoft.VisualStudioCode

安裝好後，就可以打開 VS Code，開資料夾（專案）或是單一檔案來編輯，若開啟資料夾且偵測到 git 相關檔案，則 VS Code 會自動解析 git 狀態。

這邊以我在 Linux 上撰寫 Hugo 文章為例，在 Windows 上以 SSH 遠端連線到 Linux 伺服器，並開啟 Linux 上的目錄。我切到 VS Code 內建的 Git 管理，可以看到那些檔案新增、編輯、刪除。另外，我有安裝擴充 - Git Graph，可以以圖的方式檢視目前 Git 分支的狀態。

WinCompose

針對特殊符號，系統不像 macOS 有快速鍵（compose key）。開源的 WinCompose 就是拿來補這一塊的。

以前我打特殊符號都是記 Unicode 表，甚至還印出了常用的 Unicode 表 XDD。

首先先切換到新注音輸入法，輸入 Tab 鍵盤上的前導字元 `，接著按下鍵盤 U 表示 unicode，然後輸入字元的號碼例如 2605 後按空白鍵，特殊符號就出來了。

例如：`u2605 表示 ★ | `u2606 表示 ☆ | `u00b0 表示 °

用 WinCompose 按快速鍵（右 Alt）再加上定義字元，就可以快速打出特殊符號。

例如：

  • ♥：右 Alt按一下，並輸入 <3 即可出現愛心（< 輸入方式為 Shift + ㄝ）
  • ♢：右 Alt按一下，並輸入<>
  • √：右 Alt按一下，並按下鍵盤的 sq（rt 這邊省略掉的）
  • ★：右 Alt按一下，並輸入**（* 輸入方式為 Shift + 數字 8 ）
  • ¼：右 Alt按一下，並輸入 14

安裝方式可以透過 winget 於 cmd 中完成安裝，或是到 WinCompose Release 下載並安裝：

1

winget install -e --id SamHocevar.WinCompose

安裝後，右下角會出現 WinCompose 的圖示，右鍵 → 顯示組合鍵可以看到已經定義好的規則。

左下方可以自訂快速鍵，使用上不會太困難。在此不繼續深入討論。

Windows Sandbox

Windows Sandbox（沙箱）提供輕量型桌面環境，可安全地隔離執行應用程式。在測試軟體於全新作業系統中是否正常運作、測試檔案是否有病毒或是暫時安裝某個試用版軟體(?)時非常好用。

關閉沙箱後，整個資料都會移除。每次開新的沙箱，都像全新的 Windows 一樣乾淨。

比較需要注意的是：

  1. 需要BIOS 中啟用的虛擬化功能
  2. 不支援 Windows 家用版（繞過限制）
  3. 至少 4 GB 的 RAM，但建議 8 GB 以上

安裝方式為以系統管理員身分開啟 PowerShell，輸入以下指令開啟 Windows 沙箱功能後，重新開機。

1

Enable-WindowsOptionalFeature -FeatureName "Containers-DisposableClientVM" -All -Online

執行後，就可以看到一個乾淨的 Windows。

Windows Subsystem for Linux

在 Windows 環境下部署 Linux 開發平台，有下列幾種方式：

  1. 虛擬機：使用 Windows 內建的 Hyper-V 或第三方軟體 VirtualBox，安裝完整的作業系統。
  2. 雙系統：於單一電腦上採用多重引導方式同時安裝 Windows 與 Linux，並於開機時選擇欲啟用之作業系統。（建議避免採用此方式，因可能導致系統穩定性及安全性風險）
  3. 遠端開發：配置專用 Linux 主機，用網路連線遠端操作與開發。
  4. Windows Subsystem for Linux (WSL)：直接於 Windows 系統中安裝 Linux 子系統，無需額外安裝虛擬機或安裝雙系統，即可輕鬆建立 Linux 開發環境。

WSL 的特點是占用的資源比虛擬機少，而且可以一邊用 Windows 一邊做 Linux 開發。也可以安裝和執行各種 Linux 發行版，例如 Ubuntu、Debian、Kali 等等。

安裝方式分為安裝 WSL 與 安裝 Linux 兩部分。

首先於 cmd 中輸入以安裝 wsl：

1

Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux

Windows Terminal

Windows Terminal 是微軟開發的一款跨平台終端機應用程式，簡稱終端機。支援多個 shell 環境包括 cmd、PowerShell 和 Windows Subsystem for Linux (WSL)等...。同時支援分頁顯示，分割顯示，也支援 Windows 11 的壓克力材質。

安裝方式可以到 Windows Store 中下載，或透過 winget：

1

winget install Microsoft.WindowsTerminal

安裝好後，在開始中找到終端機並執行就可以開始使用了

點選上方視窗的 ˇ 找到設定，可以修改預設設定，像是終端機預設開啟的實體，我這邊改為 PowerShell，或是也可以設定自己想要的終端實體。

預設終端應用程式可改為 Windows 終端機，未來開啟 cmd 或其他實體時，會直接以終端機開啟。

其他設定可以參考官方的詳細文件，例如更改字體、外觀，讓終端機看起來更順眼。

另外，也可以自訂設定檔，讓開新分頁的時候自動連上 SSH 或做其他操作。
