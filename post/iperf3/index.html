引言

在選購無線路由器等網通裝置時，AC3000、AX6000 以及 BE7000 等規格的路由器已經成為現代家庭網路的主流選擇。

以某品牌為例，其無線速度特性標榜如下：

Wi-Fi 5 (1024 QAM)：最高 1733 Mbps。 Wi-Fi 6 (2.4 GHz)：最高 574 Mbps。 Wi-Fi 4：最高 300 Mbps。

這些傳輸速度表示當兩個終端裝置（如手機或電腦）連接到這些 Wi-Fi 熱點時的理論最高傳輸速度。如果兩個裝置同時支援 Wi-Fi 5 和 1024 QAM，則其最高傳輸速度可達 1733 Mbps。這樣內網的兩個端點裝置就能用更高的速度傳資料。

其中需要注意的一點是，傳輸速度指的是路由器在最佳情況下所能提供的理論最高傳輸速度。實際的傳輸速度會受到許多因素影響，例如：

  1. 裝置之間的距離。（訊號越弱，通訊裝置解碼越容易出錯）
  2. 障礙物。（像是牆、轉角）
  3. 同頻干擾。（藍牙產品）
  4. 網路擁擠。（同一網路中，有多個裝置同時上傳或下載）
  5. 服務品質（quality of service，QoS）優先權。
  6. 裝置本身設計不良。（熱、天線、EMI）
  7. 線材。（網路線）
  8. 無線訊號的頻段和通道選擇。
  9. 無線協定和加密方式。
  10. 終端硬體性能。（處理器速度和記憶體大小）

也因此，若想知道兩裝置之間實際傳輸速度，可以用 iPerf3 測速與評估，外網、VPN 或是 Tailscale 的速度測試也一樣適用。

如果申請了例如 300 Mbps/300 Mbps（下載/上傳）的網路，實際的傳輸速度還是會受到多種因素影響：

測試 裝置 A 與 裝置 B，裝置 A 使用 Wi-Fi 6 網卡連接到 2.4 GHz 頻段（最高 574 Mbps）的無線路由器。無線路由器連接到對外的電信裝置（最高 300 Mbps），然後到用戶端 B 的電信裝置（最高 300 Mbps），最終速度會被限制在最高 300 Mbps。如果用戶端 B 的電信設備是 100 Mbps，則速度會被限制在 100 Mbps。

測試 裝置 A 與 手機，裝置 A 使用 CAT-5 有線網路（最高 100 Mbps）上網，而手機使用 2.4 GHz 頻段（最高 574 Mbps）連接到路由器。兩個終端裝置在內網測速時，其最高速度會受限於有線的速度而只有 100 Mbps。若要改善網路速度，可以讓裝置 A 使用無線網卡或更換網路線，例如 CAT-5e 支援 1 Gbps。

網路速度受到終端裝置的硬體參數、傳輸協定以及整個通訊鏈路（telecommunications link）中最低速度的影響。

安裝 iPerf3

Linux

官方提供的僅有 Ubuntu / Debian / Mint / Fedora / FreeBSD 的執行檔，大多可透過套件管理程式安裝。若為 ARM 架構，可透過 GitHub 直接下載 ARM 版本的 iPerf3，甚至是下載 source code 自行編譯。

以下說明測試環境為 Ubuntu 20.04 的安裝：

Windows

iPerf3 由能源科學網（Energy Sciences Network，ESnet）所維護，並提供 Linux 的編譯版本。目前 Windows 版本是由社群開發者編譯與維護的。這些貢獻者致力於將 iPerf3 經由 Cygwin 移植到 Windows 平台，並保持其與 Linux 版本的功能一致性。

Windows 平台上使用 iPerf3 需要從官方建議的站點下載。分別為：BudMan或是ar51an。

找到最新日期的壓縮檔，例如 iperf-3.17.1-win64.zip，下載後解壓縮即可使用。

指令統整說明

常見的指令如下，如果需要更進階的玩法可以參考 help。

建立伺服器iperf3 -s
建立伺服器，並指定連接埠iperf3 -s -p 5205
Client 上傳（到 Server）iperf3 -c IP_ADDRESS/HOST
Client 下載（從 Server）iperf3 -c IP_ADDRESS/HOST -R
Client 下載，並使用 4 個平行連線iperf3 -c IP_ADDRESS/HOST -P 4
指定協定版本為 IPv6iperf3 -c IP_ADDRESS/HOST -6
UDP 測試iperf3 -c IP_ADDRESS/HOST -u

建立 iPerf3 伺服器

測試兩台裝置之間的網路速度，其中 nodeA 作為伺服器，nodeB 則模擬上傳或下載的行為。

  1. 開啟 iperf3 的目錄

  2. 在路徑中輸入 cmd

  3. 跳出 cmd，確定該路徑為 iperf3 目錄底下

  4. 輸入 iperf3 -s 後會建立好 iperf3 伺服器，並開啟連接埠 5201，等待用戶端連線。

如果要自行指定連接埠，可以改為 iperf3 -s -p 5205，往後用戶端在連線需加上對應的連接埠號碼。

表格參數的意義如下，其中著重在 Bandwidth 這個參數：

  • ID：代表連線編號，用來區分多條測試連線。
  • Interval：測量時間區段，用來顯示每秒或固定區間的測試結果。
  • Transfer：在該時間區段內實際傳輸的資料量。
  • Bandwidth：在該時間區段內的平均傳輸速率（頻寬）。
  • Retr：資料遺失或損壞後，必須重新傳送的次數。次數越少，代表網路品質越好。
  • Cwnd：擁塞窗口大小，代表發送方可在等待回覆前，連續發送的最大資料量。

由上表可以得知 nodeB 傳資料到 nodeA 的平均速度為 711 Mbps。

結論

使用 iPerf3 測速後，若網速未達到需求，可以再往下除錯。

對於家用內部網路來說，線材品質、裝置設定以及協定支援等因素可能是導致網速不佳的主因。

甚至有時候重開路由器網速就正常了，遇到這種或許可以重新開始評估一台新的路由器了...。

當遇到 Tailscale 速度過慢的問題時，可以使用 tailscale ping host 命令評估裝置是否為直接連接或透過 DERP 中繼轉發。

我自己在使用 Tailscale 時通常是直接連接的，但有時連接某些 Wi-Fi 後開始使用 DERP 中繼。即使斷開 Wi-Fi 並切回原本的網路，仍無法直接連接。在這種情況下，強制重新啟動 Tailscale 服務有時會解決問題。
