什麼是 ChatGPT？

ChatGPT 是由 OpenAI 開發的語言模型，基於生成式預先訓練轉換器（generative pre-trained transformers，GPT），從大量文字內容學習自然語言處理的能力，理解使用者的輸入，並根據上下文產生對應的回應內容。

在程式碼方面，ChatGPT 能回答不同程式語言、函式庫和框架的相關問題，也能直接寫出程式碼，並解釋運作原理或給出建議。

修飾、潤稿也能給建議，或是翻譯為英文、日文等其他語言。

為目前電腦使用者基本且必備的工具。但也不應該過度依賴，畢竟產出的內容可能是錯誤資訊。

ChatGPT API 金鑰

傳統上使用 ChatGPT，會需要到官方網站，在網頁介面上輸入問題、得到回覆。

OpenAI 的 API 金鑰則可以直接存取官方 API，把服務整合到其他工具裡。

例如有了 API 金鑰，可以：

  1. VS Code 的擴充功能整合（Genie AI，問程式碼、建議分析）
  2. 瀏覽器擴充功能（ChatGPT Summary for Chrome，摘要頁面內容）
  3. 命令列介面（SGPT，在命令列直接與 ChatGPT 互動）
  4. 翻譯軟體
  5. 手機相關軟體（Keybot、OpenCat 等...）

其中 API 金鑰的定價根據官方描述，常見的模型對應售價可以整理成以下表格：

已認證的手機號碼可獲得三個月內 USD 5 的使用額度。可以到官方管道產生金鑰並直接使用。

未驗證的帳號或已用完額度的帳戶，登入 API 頁面時會產生 session API 金鑰。用這個金鑰一樣能存取 ChatGPT API，而且不用付費。

取得 session API 金鑰

  1. 首先於官網右上角登入（Login），如果沒有註冊帳號的可以直接註冊，目前註冊帳號不用驗證手機號碼了。

  2. 登入後，網址應該為 https://platform.openai.com/docs/overview

  3. 開啟開發者工具（F12），找到開發者工具內的網路標籤。

    此時重新整理網頁會看到 login，右側的預覽裡面帶有 sensitive_id，此為 session key、API 金鑰。

結論

複製 API 金鑰後，就可以貼在需要 API 的第三方應用內了。該金鑰的特點為：

  1. 效期為 14 天，過期後需要重新登入，再取得一次新的金鑰。
  2. 14 天內如果再次重新登入，該金鑰會強制過期。
  3. 僅支援 gpt-3.5 以及更低版本的模型，gpt-4 無法使用。
  4. 低調使用。
