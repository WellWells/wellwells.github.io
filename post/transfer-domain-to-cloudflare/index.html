從 Squarespace 轉移網域到 Cloudflare：完整教學與注意事項

Squarespace 的續約價從 TWD 371 漲到 TWD 457，我把網域轉去 Cloudflare Registrar。記錄從解鎖網域、要授權碼到付款的完整步驟，還有等對方放行實際花了幾天。

前言

以下內容是個人將網域從 Squarespace 轉移到 Cloudflare 的真實紀錄。

過程不算複雜，但中間有些等待和需要留意的細節，順手記下來給有同樣需求的人參考。

我的網域當初是在 Google Domains 註冊的。2023 年 Google 把 Google Domains 賣給了 Squarespace，所有網域註冊就這樣被自動搬過去了，完全沒得選。當時 Squarespace 承諾會保障 Google 原價至少 12 個月，聽起來好像還行。

但優惠期一過，續約價格直接跳漲。以我的 .com 網域為例，2026 年的續約費預估漲幅高達 23%：

項目印尼盾 (IDR)換算新臺幣 (TWD)
2025 已付款184,182.30約 371
2026 預估價245,000.00約 457

從 TWD 371 直接漲到 TWD 457，只是管個網域而已，實在沒必要多付這筆錢。剛好 Cloudflare Registrar 標榜成本價轉售、不加任何利潤，查了一下含 ICANN 費用大約只要 USD 10（約合 TWD 325），不只比 Squarespace 2026 年的預估價便宜，甚至比 2025 年已經付過的價格還低。

反正我的 DNS 本來就託管在 Cloudflare 了，網域管理權也搬過去，整合在同一平台管理會更加單純，沒什麼好猶豫的。就這樣開始了我的轉移之旅。

轉移前的準備

轉移費用

根據 ICANN 的規定，網域轉移視同續約一年，所以轉移時付的那筆錢就是下一年的年費，不是手續費。原本剩餘的效期也會完整保留，直接往後加一年，不會被吃掉。

Cloudflare 收的 USD 10.46 費用結構很透明：

  • 網域批發成本：交給註冊局的規費
  • ICANN 費用：固定規費（約 USD 0.18）
  • Cloudflare 利潤：USD 0

Cloudflare Registrar 從推出以來就走 Zero-Markup（零利潤） 路線，無論是首年註冊還是往後續約，都維持相同的成本價。不像很多傳統註冊商會用首年超低價吸引你進來，續約時再默默漲上去。Cloudflare 把網域當成進入自家生態系（CDN、安全防護、Workers 等）的入口，不靠這塊賺錢。

相比留在 Squarespace 續約要付約 TWD 457（約 USD 14.5），轉過來省下的錢一目了然，而且不用擔心哪天又被漲價。

事前確認清單

  1. Domain Lock 要先解除
  2. WHOIS 隱私保護可能需要關閉（部分註冊商要求，Cloudflare 轉移時會自動處理）
  3. 你有網域的完整管理權限
  4. 有 Cloudflare 帳號，且該網域已加入 Cloudflare 做 DNS 管理

💡 如果你的網域還沒加到 Cloudflare，建議先到 Cloudflare Dashboard 新增網站、把 DNS 指過去。轉移 Registrar 和 DNS 託管是兩件事，但先搞定 DNS 後面會順很多。

轉移時程總覽

整個流程大約 5 到 6 天，過程中網站完全不會斷線。給之後要轉的人心裡有個底：

Day 1｜2026 年 2 月 17 日：啟動轉移程序

  • 20:00 - 在 Squarespace 送出更改聯絡人資訊並取消 60 天轉移鎖定的請求。
  • 23:00 - 收到 Squarespace 寄發的網域轉移授權碼（auth-code）。
  • 23:00 - Cloudflare 通知轉移程序正式啟動，開立帳單並提交給原註冊商。
  • 23:00 - Squarespace 寄出轉移確認信，信中註明如果沒有在 2/22 前手動取消，系統就會自動放行。

Day 2｜2026 年 2 月 18 日：系統例行提醒

  • 15:00 - 收到 Cloudflare 通知，提醒網域即將到期。

Day 6｜2026 年 2 月 23 日：轉移完成

  • 13:00 - Squarespace 自動核准轉移請求，轉移順利完成。
  • 13:00 - Cloudflare 正式通知網域已成功轉入，並要求點選信件驗證電子郵件地址。

後續再次登入 Squarespace，確定網域轉移成功後，就刪除 Squarespace 的帳號了。

網域轉移完整步驟

步驟一：在 Squarespace 解鎖網域與取得授權碼

第一步是到 Squarespace 把 Domain Lock（網域鎖定）關掉。

登入後，進入 Domains → 選擇你的網域 → Overview，找到 Domain Lock 切換為 Off。

截圖中幾個重點：

  • RENEWS ON：續約日期與金額（我的是 March 3, 2026, IDR 245,000）
  • WHOIS PRIVACY：On（私人註冊）
  • DOMAIN LOCK：已設為 Off

解鎖後，頁面底部點 REQUEST TRANSFER CODE 取得授權碼（Authorization Code / EPP Code）。

⚠️ 授權碼有時效性，拿到後儘快用。

要注意的是，點了 REQUEST TRANSFER CODE 之後，網頁上不會直接顯示代碼，而是寄到管理員信箱。等了大概 2.5 小時才收到。

步驟二：在 Cloudflare 提出轉移

拿到授權碼後，登入 Cloudflare Dashboard，進到網域頁面。會看到一個「轉移你的網域註冊以降低續約費用」的開始轉移按鈕，點下去就對了。

點下去會進入 Transfer Domains 頁面，照著流程走就好。

步驟三：在 Cloudflare 輸入授權碼

在 Authorization code 欄位貼上剛才從 Squarespace 拿到的授權碼。

頁面上幾個重點：

  • 網域名稱：wellstsai.com
  • 授權碼驗證狀態：綠色勾勾代表驗證正確
  • 轉移費用：USD 10.46，之後續約也是這個價格
  • 頁面提示「Domain is within 30 days of expiration」，意思是太靠近到期日轉移有風險，建議提早動手

確認金額沒問題，點選 Continue to payment。

步驟四：填寫付款資訊

接著填寫個人資訊與付款方式。Cloudflare 支援信用卡和 PayPal 兩種付款方式。

填完送出，Cloudflare 就會開始處理轉移請求。

步驟五：等待轉移完成

送出轉移請求後，Cloudflare 會顯示「Waiting for your previous registrar to release the domain」的狀態。

頁面上會說可以回到原註冊商手動「approve」來加速，不過 Squarespace 並沒有提供手動 release 或 approve 的選項，所以就是等，最多 7 天。

等待期間可以點 View transfer status 隨時查看轉移進度。

轉移進度追蹤

Cloudflare 的 Domain Management 頁面會顯示完整的 Transfer Progress：

這時候網域狀態會顯示為 Pending Transfer，Auto-renew 暫時是關閉的。

轉移後的注意事項

幾個轉完之後要留意的事：

  1. DNS 設定不受影響：如果本來就用 Cloudflare DNS，轉移 Registrar 不會動到任何 DNS 紀錄，網站不會斷
  2. 自動續約：轉完記得確認 Auto-renew 有沒有開
  3. WHOIS 隱私：Cloudflare 免費提供 WHOIS 隱私保護，不用額外設定
  4. 60 天鎖定期：ICANN 規定轉入後 60 天內不能再轉出

結論

回頭看整個流程其實不難，核心就是：解鎖 → 取得授權碼 → 在 Cloudflare 貼上 → 付款 → 等。最花時間的反而是等 Squarespace 放行那幾天。

從 Google Domains 被收購、被迫搬到 Squarespace、再因為漲價而轉到 Cloudflare，兜了一大圈，最終算是找到一個價格合理、介面乾淨的棲身之所。

DNS 跟 Domain 管理全部在同一個地方，管起來舒服多了。早該這麼做了。
