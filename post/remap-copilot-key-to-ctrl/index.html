用 PowerToys 將 Copilot 鍵改回 Ctrl 的完整教學

新鍵盤或筆電的 Ctrl 位置被 Copilot 鍵取代，時常誤觸就跳出 Copilot 視窗。透過 PowerToys 鍵盤管理器一次解決，五個步驟將 Copilot 鍵重新對應為 Ctrl。

前言

家裡最近換了新鍵盤，習慣性按右邊 Ctrl 的時候，螢幕上跳出了 Microsoft Copilot 的視窗。

目前新出的 Windows 筆電和 PC 大多數已經標配 Copilot 鍵，對習慣用右 Ctrl 搭左手快捷鍵的人來說，這個改動就是純粹的困擾。每一次手指反射動作按下去，沒用的 Copilot 視窗就跳出來，完全打斷節奏。

用 Microsoft PowerToys 就能直接改回來，設定過程不到三分鐘。

Copilot 鍵是什麼？

微軟在 2024 年 1 月 CES 展會正式宣布 Copilot 鍵，定位為自 1994 年加入 Windows 鍵以來，近 30 年來鍵盤最重大的變革。從 2024 年初開始，Dell、ASUS、Lenovo、HP 等主要品牌的新款 Windows 11 筆電陸續加入了這顆按鍵，位置通常在右下角，取代原本的右 Ctrl。

在系統層面，Copilot 鍵的實際訊號是 Win + Shift + F23 這組快速鍵，不是一個獨立的按鍵。也因此 必須用重新對應快速鍵（Remap a Shortcut），而不是重新對應按鍵（Remap a Key），如果只是單純替換 F23 是沒有用的。

使用 PowerToys 將 Copilot 鍵改回 Ctrl

最有效的方法是用 Microsoft PowerToys 0.98+ 的鍵盤管理器。

PowerToys 是一個由微軟官方開發的免費工具集，除了替換快速鍵還有很多實用的小工具。

如果還沒裝過 PowerToys，可以參考：《Awesome Windows：必備生產力軟體安裝與說明》。

裝好之後，跟著下面五個步驟操作。

Step 1：開啟 PowerToys 設定

在工作列右下角的系統匣找到 PowerToys 圖示，點兩下開啟設定介面。

Step 2：搜尋並選擇鍵盤管理器

在設定視窗上方的搜尋欄位輸入 鍵盤，選擇 鍵盤管理器 進入。

Step 3：啟用鍵盤管理器，並開啟新版 UI

進入鍵盤管理器頁面後，啟用鍵盤管理器。

接著，建議開啟 嘗試新的編輯器，這是 PowerToys 0.98 推出的新版鍵盤管理器 UI，操作更直觀。

如果開啟了嘗試新的編輯器，按鍵和快速鍵的設定會整合成同一個編輯器介面，點擊編輯器按鈕即可同時管理，不用分開進入。如果是舊版 UI，則需往下找到快速鍵區塊，點擊 重新對應快速鍵 進入設定。

Step 4：新增重新對應

在快速鍵重新對應清單中，點擊左上角 ＋ 新增重新對應 按鈕。

Step 5：設定映射規則

在新的映射規則中，設定如下：

欄位設定值
觸發程序（快捷鍵）Win (Left) + Shift (Left) + F23
動作（對應到）Ctrl (Left)

設定完成後按 儲存。

💡 關於「允許和弦」：允許和弦是一個進階功能，讓你用一個快捷鍵組合作為前綴，再接第二個按鍵來觸發不同動作，適合將相似功能群組化。例如官方範例：Shift + Ctrl + V 後接 U 設定為音量增加，Shift + Ctrl + V 後接 D 設定為音量降低。在這裡，Shift + Ctrl + V 就成了音量控制的共同開頭。這個功能對本篇的 Ctrl 替換沒有影響，勾不勾皆可。

儲存後立即生效，不需要重新開機。

驗證是否成功

設定完成後，打開任意瀏覽器視窗，用右邊那顆 Copilot 鍵分別按 Ctrl（Copilot Key） + + 和 Ctrl（Copilot Key） + -，看網頁頁面 UI 是否正常放大與縮小。能放大縮小，就代表映射成功了。

設定摘要

步驟操作
1開啟 PowerToys 設定
2搜尋鍵盤，進入鍵盤管理器
3確認功能已啟用，開啟新版 UI，點擊 重新對應快速鍵
4新增重新對應
5觸發程序設為 Win + Shift + F23，動作設為 Ctrl (Left)，儲存

結語

這個改動花不到三分鐘，但省下的干擾是日積月累的。微軟想推廣 AI 助手的方向可以理解，但 Copilot 在 Windows 上非常難用，直接取代大家常用的 Ctrl 鍵，還是讓人有點無言。好在 PowerToys 本身就是微軟自家的工具，用它來修正這個問題，算是某種程度上的妥協。

這套方法不只適用於 Copilot 鍵。如果你想把鍵盤上的任何按鍵重新對應成自定義的功能，例如把 Caps Lock 改成 Ctrl、把沒在用的 Scroll Lock 對應成媒體鍵，PowerToys 鍵盤管理器同樣都能做到。
