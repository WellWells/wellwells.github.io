使用 VS Code 把原始資料轉為可分析的資料

帶你利用 VS Code 與正規表示式，快速從網頁原始碼中提取重複性的資料（如商品價格），並清理轉存為 Excel 可分析的格式。學會內建的多重選取與基礎 Regex 技巧，不需另外寫腳本也能大幅提升資料處理效率。

前言

現代網頁設計裡，大多數元件都是模組化結構，重複性的框架隨處可見，例如工作列表、商品資訊或連結目錄。這些重複結構也讓特定資料更容易被格式化擷取出來。

例如：

  1. 原價屋 CPU 商品頁面：如何快速取得商品的價格資訊？
  2. 敏捷開發中的看板任務：如何彙整屬於自己今年度的任務清單？
  3. 其他應用場景：例如從多個檔案中搜尋特定內容並解析。

這些情境都能在 VS Code 中快速把需要的資料抓出來，方便後續分析。

這篇會用實務操作示範，怎麼在 VS Code 裡用正規表示式從原始資料抽出有用的內容，轉成可分析的格式。

前置作業

安裝 VS Code

請先確定電腦已安裝 VS Code。如果尚未安裝，請參考《2026 Windows 必備軟體推薦：打造極致效率的 Awesome Windows 生產力與開發工具總覽》中的 Visual Studio Code 小節。

常用的正規表示式

在 VS Code 裡用尋找功能就能找到符合規則的字串，搭配正規表示式還能精準挑出想要的內容。以下整理幾個常用、開發人員幾乎都得會的正規表示式：

描述正規表示式範例說明
比對任意字元.a.c 符合 abc 或 a3c單一任意字元（不含換行字元）
符合一次或多次+a+ 符合 a 或 aaa至少符合 1 次
符合零次或多次*a* 符合 aaa 或 a 或空字串前面的字元可以出現 0 次或多次
符合零次或一次?a? 符合 a 或空字串最多符合 1 次
比對開始位置^^hello 符合 hello world行首
比對結束位置$world$ 符合 hello world行尾
符合數字\d\d+ 符合 123 或 56數字 0-9
符合字母或數字\w\w+ 符合 hello123包含字母、數字及底線 _
符合具體次數{n}a{3} 符合 aaa精確符合 n 次
符合最少次數範圍{n,}a{2,} 符合 aa 或 aaaa至少符合 n 次
符合範圍次數{n,m}a{2,4} 符合 aa 或 aaa至少 n 次，最多 m 次
符合某字元集[abc][abc] 符合 a 或 b 或 c只符合指定字元集中的字元
符合字元集以外的字元[^abc][^abc] 不符合 a 或 b 或 c符合不在指定字元集內的字元
符合換行字元\na\nb 符合 a + 換行 + b特殊字元：換行
非貪婪比對*?、+?、??、{n,m}?a+? 符合 a 而非 aaa，aaa 會符合 3 次個別的 a優先符合最少次數
分組()(ab)+ 符合 abab 或 ab將內容分組，便於擷取和重複使用
符合特殊字元（跳脫）\\[ 符合 [，\) 符合 )跳脫正規表示式的特殊字元

還有一些較特殊的正規表示式，如 先行斷言、單字邊界、非數字 等，在搜尋中較少用到，此處不詳述。有興趣者可參考 微軟的說明文件。

取得商品頁面的資訊

這個案例以原價屋的 CPU 頁面為例，頁面上有商品名稱與價格。要怎麼把網頁裡的商品名稱與售價抓出來，轉成 Excel 方便進一步分析？以下是具體的操作流程：

取得網頁原始碼

  1. 首先來到原價屋 CPU 商品頁面。

  2. 對著網頁空白處右鍵 → 檢視頁面來源（Chrome: 網頁原始碼），或使用快速鍵 Ctrl + U。

  3. 使用 Ctrl + A 全選頁面原始碼內容，然後按 Ctrl + C 複製。

  4. 在 VS Code 中使用 Ctrl + V 貼上複製的內容。

搜尋目標

在 VS Code 中按 搜尋（Ctrl + F），編輯器右上方會出現尋找條，裡面有一個 規則運算式的按鈕，要先打開它才能用正規表示式搜尋。

可以看到商品名稱被 <div class=t> 與 </div> 包起來，價格資訊在下一行，從 <div class=x> 起始，後面接一個含稅或未稅的 NT + 數字。

在搜尋欄輸入 <div class=t>.*?</div>\n<.*?\d+ 就能開始比對。

這句正規表示式可以解讀為：

  • 符合一個開頭：<div class=t> 的 HTML 標籤。
  • 接著比對任意字元 .*?，0 次或多次，使用非貪婪模式。
  • 接著符合 </div> 的關閉標記，後面接一個換行。
  • 換行後符合 < 開頭，.*?表示不知道有多長，但後續必須符合一個或多個數字 \d+。

上述的比對規則不熟悉，建議可以自己手動輸入，會更有比對的感覺。

熟悉的話甚至也可以化簡為：<d.*=t>.*?.*\n<d.*=x>.*?\d+

選取所有找到的相符項目

在 VS Code 中，可使用功能窗格或快速鍵快速選取所有符合條件的內容。以下為操作步驟：

  1. 叫出功能窗格

    按下 F1 或 Ctrl + Shift + P，在搜尋框中輸入 選取所有找到的相符項目。你也可以直接使用快速鍵 Ctrl + Shift + L。

  2. 執行選取

    確認所需條件的項目後，按下快速鍵，系統會自動選取所有符合條件的內容。此時離開搜尋狀態，即可檢視選取的結果。

  3. 複製與貼上

    按下 Ctrl + C 複製選取的內容，並使用 Ctrl + N 開啟新的空白檔案後，按下 Ctrl + V 貼上複製的內容。

  4. 調整格式

    用正規表示式把資料整理成方便分析的格式：

    • 再次使用 Ctrl + Shift + L 選取不相干的內容，刪掉。
    • 做一次正規表示式取代，把指定字串換成 \t (TAB 空格)，方便後續匯入 Excel 分析，整理成商品名稱\t價格。

貼至 Excel

資料整理好後，把結果貼到 Excel 做進一步處理：

  1. 複製選取內容 選取所有行，並按下 Ctrl + C 將資料複製到剪貼簿。

  2. 選擇性貼上 點選目標儲存格 A1，用快速鍵 Ctrl + Shift + V 做選擇性貼上，把內容貼成文字格式。Excel 會自動解析 \t，把資料分成多欄。

    • A 欄為商品名稱。
    • B 欄為商品售價。

貼上後就能接著做後續的資料處理或分析。

結論

本篇文章重點介紹如何善用 選取所有找到的相符項目 功能，篩選符合條件的內容，將其整理為結構化的資料，便於進一步分析。另外，這個功能無需開啟搜尋框即可使用，也可以選取特定字串並按下快速鍵 Ctrl + Shift + L，即可輕鬆找到所有相符項目。

搭配 VS Code 的 正規表示式，就能更精準地搜到關鍵資訊。需要大量篩選時，這些事在 VS Code 裡直接做完就好，不用丟給 GPT 也能拿到正確的資料。

正規表示式不只用在 VS Code，熟了之後在 JavaScript、Python 等程式語言與工具裡也一樣派得上用場。
