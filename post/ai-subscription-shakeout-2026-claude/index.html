2026 AI 訂閱怎麼選？漲價砍額度後 CP 值最高只剩 Claude

AI 訂閱漲價潮下，Perplexity Pro 搜尋砍到每週剩 200 次、Copilot 改 AI Credits 計費。實測 ChatGPT 與 Gemini 後，我把寫程式和查資料都收斂到 Claude。

前言

這一年多，AI 工具之間簡直是一場廝殺，每隔幾個月就有人端出更強、更便宜的方案，把前一個打下去。翻一下這個部落格的舊文，過往是誰當下 CP 值最高就推誰：

  • 2025/03：《Perplexity 深度評測：與 ChatGPT 差異、功能比較與日常應用》，用它取代日常的 Google 搜尋，還直接訂了一年。
  • 2025/04：把 GitHub Copilot 的代理模式當成寫程式主力，介紹了 《使用 GitHub Copilot 的代理模式以提升撰寫程式的效率與開發體驗》。
  • 2025/11：退訂 ChatGPT 全面轉去 Gemini，在 《2025 AI 訂閱大洗牌：GitHub Copilot 搭配 Gemini 3 的最高效益攻略》 主打家庭共享一個人只要 TWD 110。
  • 2025/12：用 Google Antigravity 一週做完一個從零開始的專案，效率高到讓我意外，寫了《Antigravity vs. GitHub Copilot：功能比較、效能與成本分析》。
  • 2026/04：Copilot 改 Token 計費漲價後發了： 《GitHub Copilot 轉向 AI Credits 計費：2026 方案解析與替代工具探討》。

一年下來，這些我推過的工具一個接一個漲價、砍額度、變不穩，CP 值跟著大跌。我的訂閱清單最後只剩一個：Claude。這篇就沿著我自己的使用軌跡，把每一家的 CP 值是怎麼崩的講清楚，也講我現在錢花在哪最划算。

查證時間：本文所有價格、額度與政策都在 2026 年 7 月初重新查過一次。AI 產業變動極快，你看到時數字可能又不一樣了，請以官方最新公告為準。

Perplexity 悄悄縮減了付費額度

Perplexity 曾經取代我的 Google 搜尋，答案附來源、查旅遊資料很快，我 2025 年 3 月還直接付了一整年。

問題出在 2026 年初，它在沒寄信通知、也沒幫舊訂戶保留原本條件的情況下，悄悄把付費額度砍了一輪。根據科技媒體的報導，大約 2 月起，Deep Research 從一天幾百次砍到一個月只剩 20 次，進階模型也從清楚的每日次數改成講不清楚的每週上限，連客服都說不出確切數字，檔案上傳則從無限改成每週上限。到了 5 月額度再度收緊，不少人反映沒用幾次就撞到天花板。這些被砍的功能，Max 方案全部標榜無限，等於先把 Pro 弄差，再引導你去訂一個月 USD 200、一年 USD 2,000 的 Max。

額度到底剩多少，Perplexity 官方是不明講的，但它有個 rate-limit API 查得到（登入後打開）。查下來，付費 Pro 方案的 Pro 搜尋現在每週只有 200 次，用完就得等下週才回補。而且額度一用完，它不會擋你、也不會提醒，而是在背景偷偷把模型降智成比較弱的 Sonar，回答品質明顯掉一截，一用馬上就發現。

Reddit 跟 Trustpilot 上一票年繳用戶罵這是先賣後砍，也有人抱怨 Deep Research 會引用根本不存在的來源。對我來說，一個查資料工具連我這週還剩幾次都不肯講，就很難再當主力。現在網路搜尋我更常用 Gemini 的 Deep Research 或 Claude，Perplexity 目前訂閱還沒到期，先繼續用著，但下次應該不會再續了。

ChatGPT 穩定但已退居備援

ChatGPT 是我最早開始用的工具，但因為一直是月繳、沒有綁定，訂閱反而沒有維持最久，Gemini 一推出年繳優惠，我馬上就轉過去了。當時最被詬病的是中文圖片生成品質很差，反而 Gemini 出來後產生的中文明顯更準確。翻譯、拍照辨識、網頁統整這些日常用途都沒什麼問題，平常用起來也算穩定，但言論審查是我不再把它當主力的主要原因。

有些很正常的需求，它會說這個不能做、那個不能碰。雖然並非天天遇到，但一觸發審查，對話流程就直接中斷。從 4o 換成 GPT-5 之後又多了些新毛病，emoji 用得很勤，回覆風格也變得刻板，動不動就搬出我不能這樣做之類的說法，感覺被限制了不少。後來 ChatGPT 又推出更便宜的 Go 方案，代價是會插播廣告，這點更是讓人詬病。

寫程式這塊，我當時主要透過 Copilot 比較 GPT-4o 跟 Claude Sonnet，兩者落差明顯，Claude 強上不少，這讓我後來對 GPT 的印象多停留在聊天表現。後來 Codex 5.3 出來，能力整個往上跳了一截，不過 Claude 這邊也陸續推出 Sonnet、Opus、Fable 幾個不同定位的模型，選擇更多，寫程式上 Codex 也就不會是我的首選，日常還是主要用 Sonnet 4.6。至於日常對話、搜尋、統整這些，Gemini 和 Claude 都能打平，我實在沒理由再多養一個 ChatGPT，就讓它退居備援了。

Gemini 家庭共享仍是最高 CP 值

Gemini 是這一年少數沒對我漲價的，也是我現在幾乎天天在用的工具。Google AI Pro 台灣 TWD 650/月，一份訂閱最多 6 人共用，還一次帶出 YouTube Premium Lite 跟 5TB 雲端空間（原本 2TB，現在免費升到 5TB），湊滿一組平均一個人只要約 TWD 110，Deep Research、NotebookLM、1M 長上下文我到現在都還在用，CP 值真的高。付費之後在 Google Antigravity 這個代理式開發平台上，也享有更高的代理模型存取額度。想再更省，部分通路到 2026/7/30 前還有 Gemini AI Pro 個人帳號的 6 人組團方案，每月六個人總共 TWD 166，是目前市面上最便宜的入手方式。

缺點也有。Gemini 的對話活動預設是開啟的，等於你的對話預設會被拿去訓練模型，也有一部分會被人工審查，付費也一樣不會自動關。這對我不算大問題，介意的話去關掉 Gemini 應用程式活動或改用臨時交談就好。型號命名則有點混亂，個人付費版有 3.1 Flash-lite、3.5 Flash、3.1 Pro 三個選擇，免費版卻只給 3.5 Flash，版本編號跳來跳去，哪一個比較好我也說不準，但日常對話我大多還是用 3.5 Flash。

查資料、跑 Deep Research、統整長文，我現在幾乎都丟給 Gemini，這個價位還沒看到對手。

GitHub Copilot 的模型與計費一路縮水

Copilot 是我最早拿來寫程式的工具，用起來感受也最深，只是變化很快。它本來是微軟的產品，教育版長期免費用，只是後來被不少人濫用，才被迫改成 Token 計費。2025 年 4 月 VS Code 剛推出代理模式時真的好用，直接在編輯器裡幫你跨檔案改程式，那陣子它就是我的主力。

結果這一年 GitHub 一路往下砍。先是學生、教育版被拿掉手動選高階模型的權限，接著砍 Sonnet、再砍 GPT-5.3 Codex，到後來手邊能無限用的就只剩 GPT-4o 這種等級的模型；原本可以無限次跑 4o、mini 的，也改成按 Token 計費。2026 年 6 月 1 日更正式全面轉成 AI Credits（1 AI Credit = USD 0.01），代理模式一跑就狂燒。

Copilot 自己不開發模型，底層用的還是 Claude、GPT 這些模型，等於是幫 Anthropic 跟 OpenAI 收 Token 費用再轉嫁給你。Cursor 是一樣的處境，Perplexity 某種程度上也是，多數人拿它們寫程式、查資料，實際上背後真正在跑的常常還是 Claude。這類工具以後只會繼續漲，但漲到最後，如果一個月都要付到 TWD 3,000 這種價位，那我為什麼不乾脆直接訂 Claude？

最讓我受不了的是企業共享池的設計。整個團隊的 AI Credits 是全員共用的，等於你在花別人的 AI Credits，我們公司 4 人團隊裡，其中一個同事完全沒有用量概念，問得很爽，每天光跑 Opus 4.7 就燒掉約 TWD 500，第一週就把四個人的額度用光，其他人幾乎沒辦法正常用，我那週只問兩個問題就直接被停用，這設計真的很糟。

代理、跨檔案重構這種吃重任務，我整組搬去了 Claude Code，同樣的預算能換到更多可用的量，幾天用下來省心太多。VS Code 裡的 Copilot 我現在乾脆整個關掉。

Antigravity 穩定度不足難以扛正式工作

2025 年 12 月我開了 Google Antigravity，前面提到那個一週完工的專案就是用它做的，當下就立刻發了一篇。它是 Google 推出、基於 VS Code 的智慧型代理優先 IDE。

但這半年用下來，問題很清楚，最痛的是額度不夠用。我常常連續問個幾次就跳 Server Error，很快把當期額度用光，有時候任務跑到一半就直接中斷，出錯還照樣扣額度，體驗很差。

隱私也是老問題，公開預覽版沒有零留存保證，你送給 AI 的程式碼可能被拿去訓練、被人工審查看到，產品裡又沒有一個清楚的關閉開關。還不至於讓我不敢丟機密內容，只是拿它處理正式工作比較不建議，大多時候我都用來做一些其他專案，或是 Copilot 額度用完時拿來頂一下。它改版到 2.0 之後整個轉成代理驅動，把不少 VS Code 原本該有的功能砍掉，像 SSH remote 這種我常用的遠端開發就直接不見了，後來我沒再追它的更新，也不確定現在補回來了沒。

它的代理編排能力我認同，但一個額度這麼容易見底、還可能不定時鎖你帳號的工具沒辦法扛正事，我只把它當第二個 IDE，拿來玩實驗性專案。

寫程式為什麼收斂到 Claude

Claude 現在幾乎每一項都做到最好。我最常用的是 CLI 跟 MCP 這兩塊整合，Skill、Plugin 也都能接上去；產圖片、產聲音相對弱一點，但要它排一份 PowerPoint 簡報、輸出成完整 PDF 還是做得到。我最在意的三件事是穩、CP 值、完整，這裡的 CP 值不是便宜，是花的錢跟換到的成效划不划算。先拿價格跟額度比一輪：

工具現在價格（2026/07）額度現況穩定度我現在的定位
ClaudePro USD 20（年繳 USD 17）；Max USD 100 / USD 200對話與 Claude Code 共用同一份額度品質與一致性佳，尖峰偶有過載主力：寫程式 + 對話
PerplexityPro USD 20；Max USD 200進階功能悄悄砍，改成不公布的每週上限尚可，但額度不透明訂閱到期不續，先用著

寫程式這塊，對我來說 Claude 已經是不二選擇。Copilot 改 AI Credits 之後成本不可預測、團隊池又一週見底，我乾脆把代理、跨檔案重構這類任務全部換成 Claude Code，最大的差別是成本可預期。它跟 Claude 對話共用同一份訂閱額度，我大概知道自己一天能跑多少，不會像按 Token 計費那樣跑之前先冒冷汗。實際跑跨檔案重構、除錯，它一次能吞下整個大檔案，還會邊講解邊改。Anthropic 最新的 Opus 4.8 在 SWE-bench Verified 上到 88.6%，是目前寫程式最能打的一批。不過跑分只能參考，實務上真正拉開差距的是調用工具跟讀圖：懂不懂在對的時機下 cmd、pwsh 去查系統狀態、找檔案，看到截圖或錯誤畫面能不能判讀完再動手。

更關鍵的是一份訂閱吃兩種需求。以前我是 Gemini 管對話、Copilot 管寫程式，等於同時背兩筆訂閱費用；Claude 把日常對話跟 Claude Code 寫程式放進同一份額度，對重度使用者清爽太多，帳也好算。

還有個很有意思的點，就算我人在 Antigravity 或 Copilot 裡，真正想叫來扛吃重任務的模型往往還是 Claude。Antigravity 的設定裡可以把預設的 Gemini 換成 Claude Sonnet 4.6 或 Opus，Copilot 的模型選單裡也早就有 Claude。這些工具漲的是外殼的價，殼裡面大家搶著用的引擎常常是 Claude，那我不如直接訂源頭。

一致性也是。寫作品質這塊，社群普遍覺得 Claude 比 GPT 跟 Gemini 穩，長文件、長流程代理任務比較不會做到一半跑偏。交代下去比較放心，這是我把它當主力的主因。

Claude 的缺點與限制

Claude 該炸的時候還是會炸。尖峰時段會過載，Anthropic 這一年需求暴衝、基礎設施明顯吃緊，529 過載錯誤和服務中斷時不時出現，2026 年 6 月還被媒體點名 12 天內第十次中斷，我忙的時候偶爾也會吃到。額度也會卡到重度使用者，3 月甚至爆過一波 Claude Code 額度掉超快的抱怨（後來查出是快取的 bug，官方有重設），加上 Max 一個月 USD 200 確實貴，整天狂跑代理還是會撞牆。長上下文也別盡信標稱值，標榜 1M Tokens，但實務上中間段落容易被忽略，別因為它上下文長就一整包全丟進去。

我相信這個服務只會越來越好，真正擔心的是現在的 Token 費用不要再漲，額度也別再被砍，不然到頭來又走上跟前面那些工具一樣的老路，逼大家往更貴的方案升級。

查資料想便宜就用 Gemini 家庭共享，行內自動補全的速度還是 Copilot 最快，這兩塊 Claude 暫時打不過。但一講到寫程式，Claude 現在沒有對手。

結論

這一年最大的變化，是各家不約而同從先用低價、免費把你養成習慣，進入偷偷跟你收真實成本的階段。Perplexity 砍額度、Copilot 把模型砍光再改 Token 計費、Antigravity 收緊免費上限，本質上都是同一件事，燒錢補貼的蜜月期結束了，而 Token 費用一路在偷偷漲。

現在想把錢花在刀口上，我的建議大概是這樣：

  • 要把程式寫好：建議先從最便宜的方案訂閱一個月實測看看，覺得夠用再往上評估；要上到 Claude Max 入門的 USD 100（約 TWD 3,200）這個價位，也可以找 2～3 人一起分攤，量就足夠拿來跑代理跟重構。我自己用量比較重，實際訂的是一個月 USD 200 這個等級。
  • 只是查資料、日常對話：Claude Pro 年繳一個月 USD 17（約 TWD 550）就夠，搜尋、統整都能打。
  • 想再省：Gemini 家庭共享一個人 TWD 110，查資料照樣夠用，只是隱私要自己顧。

我現在的答案是收斂到 Claude，但我很清楚這只是 2026 年年中的最佳解。哪天 Claude 也開始漲價、砍額度、變不穩，我一樣會毫不猶豫換掉它，然後再回來寫一篇打自己臉的文章。
