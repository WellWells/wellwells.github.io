在瀏覽器中進行完美地螢幕截圖

不裝任何擴充功能，用 Chrome、Edge、Firefox、Safari 內建的開發人員工具截取單一元件或整頁畫面，還有 Netflix 這類 DRM 內容為什麼會變黑畫面、怎麼繞過。

前言

以前截圖多半是按 Print Screen 抓整個螢幕，貼到 PowerPoint 或小畫家裡裁一裁，再複製出去分享。

Windows 10 以上的系統內建剪取工具，方便得多，快速鍵是 ⊞ Win + Shift + S，可以任意截取螢幕區域並直接把圖存進剪貼簿。macOS 也內建截圖功能，快速鍵是 Shift + Command + 4，一樣可以快速截網頁。

不過，內建截圖工具有局限性：

  1. 無法截取整個網頁的全頁內容。
  2. 在 Netflix 等受 DRM 保護的媒體上，截圖後畫面會變成黑畫面。
  3. 無法自由擷取網頁的元件內容。

這篇文章著重在各大瀏覽器本身就有的方法：不用裝任何第三方擴充功能或程式，就能突破上面這些限制，把整頁或單一元件精確地抓下來。

內建方法

Chrome

Google Chrome 是目前最受歡迎、主流的瀏覽器，內建截圖功能相對有限。最方便的做法是用系統快速鍵截圖：

  • Windows: ⊞ Win + Shift + S
  • macOS: Shift + Command + 4

要截完整網頁或特定元件，請參考通用截圖方法。

Microsoft Edge

自 2020 年以來，Microsoft Edge 基於 Chromium 引擎，成為 Windows 的預設瀏覽器。由於它與 Chrome 共享渲染引擎和 JavaScript 引擎，Edge 在效能、網頁相容性以及對現代網頁技術的支援方面表現相似。

Edge 內建了一個截圖工具，點選滑鼠右鍵 → 與螢幕擷取畫面，或按快速鍵 Ctrl + Shift + S 啟動。它可以擷取選定區域或整個頁面，也有基本的註解功能。截完之後可以複製到剪貼簿或存成檔案。

Mozilla Firefox

Mozilla Firefox 由非營利組織 Mozilla 基金會開發，是一款擁有悠久歷史的開源瀏覽器。儘管採用與 Chromium 不同的渲染引擎，因此在網頁載入速度與相容性上略有差異，但效能依然穩定。雖然近年來市占率有所下降，但開源特性和 Mozilla 持續的支援使得它依然擁有一群忠實的使用者。

Firefox 內建的截圖功能比較齊全，快速鍵與 Edge 一樣是 Ctrl + Shift + S。除了擷取畫面中的特定區域，還可以直接點選網頁上的 HTML 元件截圖，也跟 Edge 一樣可以選 儲存完整頁面 或 儲存可視範圍。

Safari

Safari 是 macOS 上的預設瀏覽器，但與 Chrome 一樣，瀏覽器內部缺乏對使用者右鍵的截圖功能。可以用系統快速鍵做區域截圖（Shift + Command + 4）。

要截完整網頁或特定元件，請參考通用截圖方法。

通用截圖方法

物件截圖

主流瀏覽器的開發人員工具都有精確截圖功能，可以截取特定網頁元件或整個頁面。步驟如下：

  1. 於 Chrome / Edge / Firefox / Safari 中，開啟開發人員工具。其快速鍵為 F12 或是 Ctrl + Shift + I。或是可以於視窗右上方的列表中 → 更多工具 → 找到開發人員工具。
  1. 選擇元素選取器，找到你想要擷取的目標元素，對著 HTML 原始碼滑鼠右鍵並選擇擷取節點螢幕擷取畫面，就能精確截下該元件。

整頁截圖

要擷取整個網頁的截圖，打開開發者工具，選擇 <html> 或 <body> 元素，滑鼠右鍵並選擇擷取節點螢幕擷取畫面。這個方法在大多數網頁上都有效，但對於動態渲染的網站，可能需要使用第三方工具來模擬滾動並拼接圖像。

模擬不同裝置的截圖

選取元件按鈕右邊那顆是切換模擬裝置（Ctrl + Shift + M），可以模擬不同裝置的長寬高與使用者代理（user agent），看看頁面在各種裝置上長什麼樣。

在模擬裝置模式下，右上方的箭頭展開可以看到直接擷取可視範圍或是擷取整個頁面的按鈕，用這顆按鈕截圖也可以。

Netflix 中的截圖方法

Netflix 等串流媒體使用數位版權管理（digital rights management，DRM）保護影片內容，由 Widevine 服務負責解密和渲染。瀏覽器預設會啟動硬體圖形加速，此時走的是 Widevine L1 層級的保護，把解密與渲染的工作委派給硬體（如 GPU）。L1 依賴受信任執行環境（trusted execution environment，TEE），所以影片截圖或錄影都會是黑畫面。

停用硬體加速後，瀏覽器會改用軟體解碼，不再交給 GPU。軟體解碼沒辦法像硬體解碼那樣依賴 TEE，所以截圖和錄影就不會是黑畫面。

Chromium 核心的瀏覽器內部都有圖形加速的開關，關掉之後用內建的截圖方式就抓得到畫面。

硬體加速還開著的時候，改用物件截圖也沒用，對 <video> 節點下擷取節點螢幕擷取畫面一樣是黑的。等硬體加速關掉之後它才派得上用場，好處是可以只截影片本身，不會把播放器的控制列一起帶進去。

結論

我平常用的瀏覽器是 Edge，所以大部分時候就是 Ctrl + Shift + S 截完直接分享。要整頁或特定元件的話，我會直接打開開發人員工具，對著該物件右鍵擷取節點螢幕擷取畫面，比另外開一套截圖軟體快。
