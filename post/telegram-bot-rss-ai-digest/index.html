用 Telegram Bot 自動收 RSS 摘要：不用 API Key 的完整教學

接上 Telegram Bot 之後，在 Yobi 套一條 RSS 摘要流程：貼上網址、設定每 10 分鐘檢查一次，有新文章就自動整理好推到手機。不用寫程式，也不需要 API Key 或伺服器。

前言

在手機主動推播的演算法還沒成形之前，多數人取得資訊的方式不外乎是把常看的網站加進書籤、定時回頭看，或是用 RSS 閱讀器訂閱想追的網站。後來 Google Reader 停掉，我跟著大家轉去用 Feedly，一用就是好幾年，Feedly 後來自己也做了 AI 摘要，長文一鍵就能收成幾句話。

但說到底，RSS 已經是上一個時代的技術。FB、Google News 這類會主動推播的產品出現之後，RSS 這種要自己訂閱、自己回頭看的方式，漸漸變成一種被動、慢半拍的資料來源，塞進來的雜訊常常比真正想看的內容還多。

所以我要的其實是反過來，新文章自己送到手機上，而不是等我想起來去看。要做到這件事，一般會想到 IFTTT、Zapier、n8n 這類自動化平台，但介面主要是英文，想接上 AI 摘要還得綁信用卡、申請一組 OpenAI API Key，之後看著用量計費。對剛入門的人來說並不輕鬆。

這篇要走的是另一條路。用一台你本來就開著的電腦，把已經登入的 AI 網頁介面當成引擎，排一條流程，讓它定時去看有沒有新文章，有就整理好推到手機的 Telegram。全程滑鼠點完，不會出現終端機。

工具是 Yobi，我自己寫的開源桌面 App（MIT 授權，Windows 與 macOS）。它的整體介紹我之前寫過一篇《Yobi：用內建瀏覽器操作網頁版 AI 的自動化工具，打造專屬 Agent》，這篇則專門把最多人問的那條流程從頭到尾做完。

這篇會做出什麼

做完之後你會有一個專屬的 Telegram 機器人，每 10 分鐘檢查一次你訂閱的網站，有新文章就自動私訊你。範本內建的提示詞會把每篇文章整理成固定格式：一行可以點的粗體標題連結，接兩段各百來字的說明，前段講發生了什麼事，後段收攏數字與規格，最後補幾個 hashtag。文章頁抓得到封面圖的話，這段文字會當成那張圖的圖說一起送出。

需要準備的只有三樣，一台 Windows 或 macOS 電腦、一個 Telegram 帳號、一個你想追的網站。

前置作業做完之後，剩下的部分大概 5 分鐘。

前置作業：安裝 Yobi、接上 Telegram Bot

這兩件事我在上一篇已經寫過，直接跟著做就好：

  • 下載與安裝 Yobi：Windows 走 Microsoft Store，macOS 把 .dmg 拖進應用程式資料夾。
  • 用 Telegram Bot 遠端操控 Yobi：跟 BotFather 申請 Bot Token、貼進 Yobi 的 Bot 整合設定、產生配對碼配對帳號。

裝好打開長這樣。上方的聊天、流程、日誌、設定四個分頁，這篇會輪流用到。

Token 弄丟了不用重新建一個 Bot，在 BotFather 打 /mybots 選那個 Bot，按 API Token 它會再給你一次。跟著做完，已配對對話裡會出現你的帳號、卡片右上角的狀態變成綠色的執行中，就可以往下排流程了。

第一步：套一條 RSS 摘要流程

切到上方的流程分頁，把游標移到左上角的新增流程按鈕，選單裡選範本。

點第一個 RSS 文章摘要，畫面會換成設定精靈，只要填兩格。

  • 要追蹤哪個 RSS 訂閱源：貼上 https://9to5mac.com/，再按下方的「從網站探測 feed」，它會自己找出這個站的 feed 網址。知道網址的話也可以直接貼。
  • 訊息要送給誰：從配對過的帳號裡選你自己。

網址還沒填的時候，右下角的加入我的流程按鈕是灰的，填完就會亮。按下去，流程就建好了，而且直接是開啟狀態。

同一個選單裡還有「用 AI 建立」，用一句話描述你要的自動化，例如每個工作日早上 8 點抓我的 RSS，逐篇用 AI 摘要後傳到 Telegram，它會幫你把整條流程排出來。這篇要做的東西範本已經有了，直接套比較快，範本庫裡找不到的組合再用這個。

第二步：設定每 10 分鐘檢查一次

流程最上方是觸發方式，範本預設是排程，平日早上 8 點跑一次。想每 10 分鐘看一次，把「每週」切成「間隔」，每隔填 10、單位選分鐘，按儲存。

間隔設得密不會變成洗版。RSS 步驟會記住上次讀到哪裡，推送過的文章有快取，下一輪不會再送一次，所以每 10 分鐘跑只是讓新文章早點到手。另外第一次執行只會抓最新一篇，先建立檢查點，免得整個訂閱源的舊文章一次灌爆你的手機。之後每一輪最多也只送 5 篇。想從頭再抓一次，RSS 步驟上有個清除檢查點的按鈕。

想馬上確認會不會動，按旁邊的執行手動跑一次。它要開網頁抓內文、再讓 AI 讀完寫好摘要，等半分鐘到一兩分鐘都算正常。畫面上不會有進度條，想看它跑到哪一步，切到上方的日誌分頁。

Yobi 是桌面程式，排程只有在電腦開著、Yobi 在跑的時候才會執行。到 設定 → 一般 的系統匣區，把「開機時自動啟動」和「關閉視窗時隱藏至系統匣」都打開，它就會安靜待在背景。家裡有 24 小時不關機的主機，放那台最合適。

觸發方式不只排程。同一排頁籤切到 Bot，填一個指令名稱，之後在 Telegram 對機器人打 /news，流程就跑一次，不想定時被打擾、想看再叫它的人適合這樣設。指令後面接的文字會存進指令參數變數名稱那格指定的變數，後面的步驟可以拿來用，例如塞進提示詞當關鍵字。

想換摘要格式，就改提示詞

這條流程一共 14 步，骨架是抓 RSS → 逐篇打開文章讀內文 → 交給 AI → 推到 Telegram，其餘都是某一篇抓失敗時跳過它、繼續跑下一篇的判斷。真正決定訊息長什麼樣的只有一格。

在流程編輯器往下捲，找到 LLM 摘要這張卡片。

中間那一大格就是提示詞，範本已經幫你寫好（英文寫的，輸出會跟著你的語言走）。想要別的格式直接把它換掉，例如：

用繁體中文整理這篇文章，格式如下：
第一行是文章標題，做成粗體並且連到 {{item.link}}。
接著三句話講完這篇在說什麼。
最後一行寫「值不值得點進去看」，一句話。

欄位下方會列出當下可以用的變數，{{item.title}} 和 {{item.link}} 是這一篇的標題和連結，點一下就插進去。改完按儲存，再按執行看一次實際送出來的訊息，不滿意就再改，這一格改壞了也不會影響其他步驟。

再往下捲到最後一張 Telegram 通知。訊息欄填的是 {{llm_1}}，也就是上一步 AI 寫出來的東西；附件欄是擷取網頁時抓到的封面圖，有圖的時候訊息就變成圖說，前面的範例就是這樣來的。想同時送給家人，在聊天 ID 底下多點一個配對過的帳號就好。

追蹤沒有 RSS 的網站

有些網站根本沒提供 RSS，或者你只想盯站內的某一頁，像是某家公司的新聞稿列表。範本庫裡的「自訂網頁追蹤」就是做這個的，設定精靈比 RSS 那個多一格。貼上網址之後按「點選清單」，它會開一個視窗載入那一頁，你在頁面上點任何一篇文章的標題，它就知道清單長什麼樣、連結在哪。

之後每一輪它會比對那一頁有沒有新項目，有才往下跑。擷取內文、摘要、推播那幾步跟 RSS 那條完全一樣，提示詞也一樣改。

YouTube 頻道也有範本

範本庫裡的 YouTube 新片摘要是同一副骨架的影片版。第一步換成 YouTube 訂閱，頻道清單一行填一個，@帳號 或頻道網址都收，略過 Shorts 打開就只留一般影片。之後的步驟是抓新影片的字幕、交給 AI 整理、推到 Telegram。新加進去的頻道一樣只會先抓最新一部，不會把整個頻道灌過來。

結論

自從這條流程跑起來，我就很少再打開 Feedly 了。想追的網站排進去，新文章自己到手機上，看完標題和兩段摘要就知道要不要點進去。之後想換追蹤的網站，回到那條流程，把流程設定裡的訂閱源網址換掉就好，不用重排一次。

範本庫裡其他幾條也都是同一副骨架，多排幾條互相搭配，RSS 一條、YouTube 一條，再加一個在 Telegram 打指令就叫得動的，比較複雜的事也做得起來。

如果你想到其他好用的組合，或對 Yobi 有建議，歡迎到 GitHub 開 Issue 一起討論，原始碼也都在上面。覺得有幫助的話，可以到贊助頁面請我喝杯咖啡，或直接幫專案點顆 ⭐。
