用 line-cli 讓 Claude Code、Codex 讀取並摘要 LINE 群組訊息

line-cli 讓 Claude Code、Codex 讀取 LINE 電腦版的聊天紀錄，不用申請 LINE Bot，也不必逐一複製對話，就能摘要群組訊息、整理廠商還沒回覆的問題。

公司跟 A 廠商開一個 LINE 群組，跟 B 廠商再開一個，幾個案子加起來，手上就有十幾個群組。早上打開 LINE，我想先知道今天該回誰。A 廠商昨天問我這版圖面能不能送印，這則訊息很快就被後面的照片和一長串收到、謝謝蓋過去。

想快速知道群組裡在講什麼，又懶得一則一則往上翻的時候，以前我會逐一打開聊天室，選取對話，複製到網頁版 Gemini 或 ChatGPT 請它整理。等我把訊息貼齊，自己也已經從頭翻過一輪了。所以我寫了 line-cli，這是一套 Windows 命令列工具，直接使用這台電腦已登入的 LINE 帳號讀取和傳送訊息，不需要申請 LINE Bot，也不用架設 webhook。現在我只要告訴 AI 助理要看哪幾個群組，它就會讀取對話，列出還在等我回答的問題。

請 AI 助理安裝 line-cli

line-cli 支援 Windows 10 和 11 的 x64 電腦，安裝前要先在這台電腦登入過一次桌面版 LINE。接著打開平常用的 Claude Code、Codex 或 Antigravity，把下面這段話貼進對話框：

1
2

請依照 https://github.com/WellWells/line-cli 的安裝說明，在這台電腦安裝 line-cli 和你會用到的 skill。
裝好後告訴我版本，以及哪些 AI 工具已經裝好這個 skill。

skill 是寫給 AI 助理看的使用說明，安裝程式會把它裝進這台電腦上偵測到的 AI 工具。安裝完成後要完整關掉 AI 助理再重新開啟，新的 skill 才會載入。從終端機啟動的話，請開一個新的終端機視窗再啟動。

用 PowerShell 安裝 line-cli

不透過 AI 助理也可以自己安裝。按 Win + R 開啟執行視窗，輸入 powershell 後按 Enter，不需要以系統管理員身分執行。把下面這行貼進 PowerShell 視窗，再按 Enter：

1

irm https://github.com/WellWells/line-cli/releases/latest/download/install.ps1 | iex

安裝程式會先下載並核對檔案，裝好 line-cli 本身：

第一次安裝時，最後還會提醒防火牆的事。傳送訊息和下載檔案需要連到 LINE 的伺服器，檢查新版本則會連到 GitHub。如果防火牆預設封鎖新程式，要放行一次 linecli.exe，PATH 上的 line.exe 不會連網，不必放行。之後更新會裝到同一個路徑，不必重新設定規則。

整理 LINE 群組裡還沒回覆的問題

舉個例子，廠商一多的時候，我會先請 Claude Code 列出最近聯絡過哪些廠商：

Line 最近聯絡的廠商有誰？

助理依聊天室名稱分成官方帳號、群組和個人聊天，並列出每個聊天室最後一則訊息的日期。這一步只看名稱，沒有讀訊息內容。最後它反問廠商的範圍要不要包含銀行、診所這類服務單位，確認後再讀取這些聊天室的內容。

我回答只列供應商，再請它整理這一週還在等我回覆的問題：

只列供應商。幫我看這些廠商群組這一週的對話，按廠商列出還在等我回覆的問題，有提到期限的也標出來。

這一週有新訊息的供應商群組只有 5 個，其他群組的最後一則訊息都早於這週，助理直接略過。每個群組底下分成待我表態、待廠商回覆和期限三類，最後列出今天要處理的兩件事，其中一件是對方在群組裡點名問我、我還沒回的問題。LINE 本身沒有待回覆的標記，這些都是助理讀完對話內容後判斷的。

整理完之後，可以接著請助理分析某家廠商的問題並草擬回覆，也可以直接請它透過 line-cli 把回覆傳到群組裡。真的要傳的時候，助理會先列出收件人和完整內容，我確認沒問題才讓它送出。傳 JPEG 照片時，line-cli 會跟 LINE App 一樣先去掉 GPS 拍攝位置，電腦上的原檔不會被修改。

摘要訊息很多的 LINE 群組

人多的群組一天就有幾百則訊息，我也會請助理直接摘要。LINE 內建的 AI 訊息摘要只支援手機版的社群聊天室，一般群組和電腦版都用不到。line-cli 讀的是電腦版的聊天紀錄，一般群組也能摘要。下面以一個公開的大台南美食社群為例，我在 Claude Code 輸入這句：

分析 line 上 大台南 群組最近的內容

Claude Code 載入 line-cli 的 skill 後執行了五個指令。它先統計 11 月 10 日到 26 日約 5,166 則訊息，平均每天約 300 則，再實際讀了 25 日上午約 200 則訊息，以及這段期間提到推薦的訊息。發言統計顯示約四成訊息來自前三名成員。它也提醒本機資料只同步到 26 日 13:02，LINE 上還有較新的訊息沒有同步，要補齊得在 LINE 裡打開這個群組。line-cli 讀得到社群的訊息，但不能在社群裡傳送訊息。

還可以請 AI 助理處理的 LINE 工作

line-cli 負責讀取、下載和傳送 LINE 的訊息與檔案，分析和整理則交給 AI 助理。下面這些都可以直接交代：

  • 上週在 LINE 收到的檔案，幫我備份到 Google Drive。
  • 分析今天廠商傳來的 Datasheet，列出跟我們規格不合的地方。
  • 整理主管這週在 LINE 交代的需求，寫成一份完整的 Word 報告。
  • 從圖片資料夾挑一張早安圖，傳給爺爺。
  • 家人群組的記事本裡，週末聚餐約在哪裡？
  • 把家人群組相簿裡這個月的照片全部下載下來。
  • 在專案群組標記阿志，問他測試進度。
  • 我剛才傳錯的那則訊息，幫我收回。
  • 等小明回覆，有回覆就告訴我。

備份到 Google Drive 和產生 Word 報告時，line-cli 只負責下載檔案和讀取訊息，上傳和寫檔要靠 AI 助理本身的工具，例如這台電腦已經安裝 Google Drive 電腦版。傳訊息、收回訊息，或是新增、刪除記事和照片之前，助理都會先讓你確認。

line-cli 常用指令

AI 助理讀取和傳送訊息時，執行的也是這些指令。指令預設輸出 JSON，加上 --text 比較好讀。下面的輸出是在我的電腦上實際執行的結果，訊息內容和 id 已經替換掉。

先用 line chats 找聊天室，名稱只要輸入一部分：

2

回傳的筆數等於 --limit 時，第二行的 note 會提示可能還有更早的訊息，要往前讀就加上 --until，填入第一則訊息的時間，那一秒內的訊息會重複出現一次。

傳訊息前先加 --dry-run 預覽收件人和內容，這一步不會送出。--to 不能只輸入部分名稱，要填完整的聊天室名稱，或 line chats 查到的 chat_id：

確認沒問題，把 --dry-run 換成 -y 才會真的送出。其他常用的指令：

想做什麼指令
看各聊天室的未讀訊息line unread --text
跨聊天室搜尋訊息line search "圖面" --since 2026-11-01
傳檔案line send --to 小各 --file .\圖面.pdf -y
讀群組記事本line notes 家人群組 --text

執行 line help 可以看到所有指令，單一指令的參數用 line read --help 這種方式查詢。

用 Yobi 在手機 LINE 上交代 AI 任務

line-cli 要在電腦前的 AI 助理裡使用。人不在電腦前時，可以改用我寫的 Yobi。Yobi 內建 LINE（本機）連接器，讀寫 LINE 的方式跟 line-cli 相同。到 Yobi 的 設定 › 連接器 › LINE（本機） 開啟後，Yobi 的 Agent 就能搜尋、讀取 LINE 電腦版的對話，也能用你的帳號傳送訊息和檔案。

要從 LINE 交代任務，還要到 設定 › Bot 整合 › LINE PC 啟用 LINE PC Bot。接著用手機在任何群組或 1 對 1 聊天裡，傳一則以 Yobi 開頭的訊息，例如 Yobi 明天會下雨嗎，Yobi 就會用你的帳號回覆，回覆開頭標著 [Yobi]。群組裡其他人第一次叫 Yobi 時，Yobi 會先請你允許。這個方式不需要建立 LINE 官方帳號，也不用設定 webhook，但電腦要保持開機，Yobi 和 LINE 電腦版也要開著。Yobi 的流程可以把整理好的結果傳到指定的 LINE 群組或好友，同一個 Agent 也能從 Telegram、Discord、Slack 接收任務。
