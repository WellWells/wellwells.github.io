前言

藝人黃子佼近期捲入桃色風波，該事件引發廣泛關注並促使媒體報導「創意私房已關閉」。許多出於好奇心嘗試存取該網站的使用者，卻發現其網址遭到劫持，最終被導向臺灣網路資訊中心（TWNIC）指定的封鎖頁面。

臺灣網路資訊中心（Taiwan network information center，TWNIC）是管理臺灣網域（.tw、.台灣）與 IP 位址的機構，負責網路資源分配、技術教育推廣、國際合作及網路安全發展。

網路自由

網路本質上是自由的，這裡說的自由是指使用者能連到任意網站。但受到法規限制，政府可能會管制或禁止部分特定網頁的存取。例如在中國大陸，常見的被封鎖對象包括 Google、YouTube、Facebook、維基百科 等。

網路自由並不意味著對色情、賭博、盜版等行為的容忍或鼓勵，尤其當這些活動建立在剝削他人痛苦或侵犯他人權益的基礎上時。這些行為本質上就不應受到支持或鼓勵，且若有人因接觸此類內容而進一步涉入犯罪或非法活動，將可能引發更嚴重的社會問題。

臺灣早在 2013 年，因應國內外部分網站提供侵權內容，智慧財產局就建議國內 ISP 用 DNS 或封鎖 IP 位址的方式來擋，但最終沒有落實。

在近期新聞媒體的渲染下，使用者點選創意私房時，會發現網址被轉導到封鎖頁面。其實早自 2020-03-30 起，TWNIC（財團法人臺灣網路資訊中心）就召開了 第一次 DNS RPZ 會議，用 DNS 等方式做網路封鎖，一路持續到現在。

回應政策區域（DNS RPZ）

什麼是 DNS RPZ

域名系統回應政策區域（domain name system response policy zone，DNS RPZ）是一項由 網際網路系統聯盟 開發的技術，旨在於 DNS 伺服器層級實現網址過濾機制。

RPZ 讓網路管理員在 DNS 伺服器裡設定特殊的回應政策區域，當查詢碰到受限制的網域時，DNS 伺服器就依預設策略回傳指定的 IP 位址或錯誤訊息，把流量重新導向或直接擋掉，用來阻止存取惡意網站、釣魚網站或政治不正確的內容。

舉例而言，若使用者欲瀏覽 NSFW.com，其正確 IP 位址為 1.2.3.4，但若該網域已被列入中華電信（DNS 伺服器 IP 位址：168.95.1.1）的 RPZ 過濾名單中，DNS 解析後將回傳 NXDOMAIN 或被重新導向至特定 IP 位址，導致無法正常取得該網站內容。

相對地，若將 DNS 伺服器改為使用未參與 RPZ 過濾的公共 DNS 服務（如 CloudFlare 的 1.1.1.1），則在解析 NSFW.com 時不受過濾名單影響，能夠正常解析並取得該網站的原始內容。

誰使用了 TWNIC 的 RPZ？

根據 2024/04 擷取自 TWNIC (網址已失效) 的資料，目前已參與該機制的成員包括：

  1. 教育部（Ministry of Education Republic of China）
  2. 中華電信（Chunghwa Telecom）
  3. 臺灣碩網（So-net Taiwan）
  4. 宏遠電訊（SaveCom International）
  5. 中嘉和網（KBT）
  6. 大臺中數位有線電視（VeeTIME Corp.）
  7. 天外天數位有線電視（TWT Digital Communication Corporation）
  8. 正源科技（Yulon IT Solutions）
  9. 臺灣固網（臺灣大哥大）（Taiwan Fixed Network）
  10. 新世紀資通（遠傳）（New Century InfoComm Tech，NCIC）
  11. 亞太電信（Asia Pacific Telecom，APT）
  12. 臺灣之星（Taiwan Star Telecom，T Star）
  13. 三大有線電視（SAN DA CATV）
  14. 公共電視（Public Television Service，PTS）
  15. 統一資訊（President Information）

換句話說，如果你用的是中華電信、臺灣固網、遠傳等網路服務，預設的 DNS 伺服器都會用 RPZ 過濾。

RPZ 安全嗎？

域名解析的核心，就是把網址轉成對應的 IP 位址。把網址送給 DNS 伺服器時，伺服器只會記錄你請求的域名，不會碰到網頁內容或傳輸中的敏感資訊（例如密碼、個人資料）。DNS 伺服器回傳的是經過過濾、或確認安全的 IP 位址，讓連線相對安全。

例如，當使用者嘗試瀏覽 NSFW.com，若其域名遭到劫持而回傳 150.242.101.120，瀏覽器將比對該連線的憑證。若憑證與預期域名不一致或連線使用 HTTP 協定，則會顯示不安全提示。使用者若選擇忽略警告，則最終會被重新導向到 TWNIC 指定的封鎖頁面。

另外，如果電腦的「受信任根憑證」被竄改，就算域名被劫持、又信任了可疑憑證，瀏覽器也可能發不出有效警告，攻擊者就能做中間人攻擊（MITM），攔截並解析所有網頁傳輸內容，做更精準的封鎖。所以用公用電腦時，盡量別做登入這類敏感操作，降低風險。

相關應用

對於相關應用，使用者可以自行建立 DNS 伺服器來過濾廣告、病毒、色情及釣魚網站等不良內容，自行架設的 DNS 伺服器在功能上與 RPZ 相似。目前市場上有現成方案，例如免費的 NextDNS 或可自行架設的開源工具 AdGuardHome。

如何避免網路封鎖

前面講的其實就是 DNS 解析被套了一層 RPZ 而已。想正常瀏覽網站，建議別用這些機構預設的 DNS 伺服器。較新的系統可以設定 DNS over HTTPS（DoH），防止攻擊者偽造 DNS 訊息。從網管的角度看，DoH 流量和其他 HTTPS 流量長得一樣，網管也就更難追蹤使用者瀏覽了哪些網頁。

行動裝置

行動裝置上，大部分新系統都支援 DNS over HTTPS（DoH）。以 iPhone 為例，安裝 mobileconfig 設定檔 就能啟用。裝好後，手機所有流量都會走指定的 DNS 伺服器解析，你可以挑 Google、Cloudflare 或 Quad9 這些公認的 DNS 伺服器。

  • Cloudflare 1.1.1.1
  • Cloudflare 1.1.1.1 Security
  • Google Public DNS
  • Quad9
  1. 點選上述連結後，選擇允許安裝描述檔。
  2. 前往系統中的「設定」→「一般」→「VPN 與裝置管理」。
  3. 在「已下載的描述檔」中，找到 Cloudflare DNS over HTTPS 描述檔，然後點選右上角的「安裝」。
  4. 進入「DNS」設定，將「自動」切換為「Cloudflare DNS over HTTPS」。

完成以上步驟後，手機就會以 DoH 查詢域名，避開 DNS 劫持，隱私也多一層保護。

備註： 請注意，DNS over HTTPS（DoH）僅為加密 DNS 查詢的技術，並不等同於虛擬私人網路（VPN）。

結論

網路審查是很複雜的議題，牽涉政府、企業與使用者之間的持續拉鋸。以中國大陸為例，使用者冒著違法風險用 VPN，搭配各種加密協定（如 Shadowsocks、V2Ray、Trojan、Hysteria、Juicity、WireGuard、Snell）翻牆；臺灣這邊則是市面上一堆 VPN 服務，付費訂閱就能繞過限制，最後賺到的只有 VPN 供應商、中繼商跟 VPS 供應商。

而且盜版商的網站 NSFW.com 一旦被封，對方換成 NSFW.ai 或 NSFW.io 就好，政府很難即時擋掉。內容甚至靠 Telegram、Line、Facebook 和各種私密群組分享、販售，封鎖等於形同虛設。就像新聞把「創意私房已關閉」講得很大，反而讓更多人認識了這個網站。

成人內容產業涉及廣泛的倫理與法律問題，但當市場需求存在時，即使花費巨額資金取得內容，產業仍難以徹底瓦解。真正的解決之道在於釋出高額獎金以捉拿幕後操控者（例如拍攝者或詐騙廣告投放者），並實施嚴格法律制裁；對於屢次違規者，則採取全面封鎖措施。

但色情產業能不能真的根除，其實很難說：想看的人總能找到辦法，甚至願意付更高的價錢。另外，Apple 於 2021 年曾提出兒童性虐待素材（child sexual abuse material，CSAM）檢測系統，打算比對使用者 iCloud 照片與兒童保護組織提供的已知 CSAM 圖片雜湊值來偵測相關素材，最後因為爭議與準確性問題沒有推行。

期盼未來能有更完善的措施，減少因脅迫而拍攝的不良影片，以及那些沒營養價值的詐騙垃圾廣告。
