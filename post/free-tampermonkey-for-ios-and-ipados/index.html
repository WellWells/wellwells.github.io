如何在 iOS 及 iPadOS 上取得免費的 Tampermonkey

竄改猴（Tampermonkey）在 App Store 要價 TWD 90。我用公開腳本申請免費授權的流程：作者開出的三個條件、促銷碼怎麼申請，以及代碼怎麼兌換。

前言

竄改猴（Tampermonkey）這款使用者腳本管理工具，於 2024-11-19 正式上架 App Store，售價為 TWD 90（約 USD 2.99）。裝了它就能自己寫腳本、管理腳本，自由自訂網頁功能，例如：

  • 移除網頁元件、廣告
  • 在 YouTube 上顯示下載連結
  • 修改網頁主題
  • 其他...

竄改猴支援主流瀏覽器，包括 Chromium 核心的瀏覽器（如 Chrome、Edge）以及 Safari 和 Firefox。但 Safari 版本無論在 macOS 或 iOS 平台，都要付費才能下載。

在 iOS 平台上，早期曾推出一些其他的腳本管理工具，例如免費的 Userscripts 和 Stay for Safari。不過這些工具實際操作體驗上，都無法與竄改猴相媲美。

本篇文章將著重於如何在 iOS 或是 iPadOS 平台上免費取得竄改猴。

申請免費授權

根據作者說明，取得免費授權需要符合：

  1. 曾經的捐款者。
  2. 在 GitHub 上提交問題或發表評論幫助過的使用者。
  3. 開發受歡迎腳本的使用者。

滿足上述三個條件的任一都可以取得免費授權，是相對寬鬆的。而我抱著開發者的心態於促銷碼申請提交先前所撰寫的公開腳本。

接收驗證信與更新腳本

送出申請後，會收到促銷碼申請 ID。根據信件內容，首先於腳本的標頭新增註解標籤：

1

// @tampermonkey-safari-promotion-code-request

接著，於 Grease Fork 發訊息給作者，並提供促銷碼申請 ID。

結論

竄改猴（Tampermonkey）是我電腦瀏覽器中必備的腳本管理工具，Grease Fork 上有許多現成腳本，像是防止網頁閒置、自動移除追蹤碼，或將靜態網址轉換為超連結。竄改猴內建 Google 同步功能，語法支援也做得不錯，這些優勢讓它拿下臺灣生產力工具類排行榜的第一名。

對於有需求的使用者，可以直接於 App Store 購買。如果不是腳本開發者，應該也可以先捐款再嘗試促銷碼申請，我想無論捐款金額，後續提出促銷碼申請應該都是可以被審核通過的。
