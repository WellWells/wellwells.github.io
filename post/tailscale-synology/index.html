在 Synology NAS 上安裝最新版本的 Tailscale

套件中心的 Tailscale 版本一直落後官方好幾版，這篇改從官方 spk 手動安裝，再用 Synology 的任務排程自動更新。DSM 6 與 DSM 7 都適用。

引言

在上一篇文章 使用 Tailscale 輕鬆建立安全且私密的隧道 中，我介紹了如何使用 Tailscale 建立專屬於個人的安全私密 VPN（tailnet）。

這篇著重在如何於 Synology 上安裝最新版本的 Tailscale，並設定自動更新，讓 Tailscale 一直維持在最新版。

系統配置

本文的操作環境如下：

  • NAS 裝置：DS220+
  • 作業系統：DiskStation Manager 7 (DSM 7)
  • 處理器：Intel Celeron J4025
  • Synology 軟體包架構：Geminilake
  • 通用架構：x86_64

要安裝最新版本的 Tailscale，得先確認 NAS 的通用架構，這會決定要下載哪一個 Synology 軟體包（.spk 檔案）的網址。

如果不確定 NAS 的架構，可以參考 Synology 和 SynoCommunity 套件架構 取得 NAS 的詳細資訊。

傳統安裝方式

傳統的安裝方法是從 Synology 套件中心裝 Synology 自己釋出的版本。

  1. 點選左上角的 主選單 按鈕，然後選擇 套件中心。

  2. 在所有套件中找到 Tailscale，點選安裝。

  3. 安裝完成後，在主選單中點選 Tailscale 並登入使用。

    在套件中心檢查已安裝版本，確認為官方版本 1.58.2-700058002。

此版本是 由 Synology 發布（2024/04/18）。

根據 Tailscale 的最新官方版本，最新版本為 1.82.5（2025/05/04）。

從官方網站安裝最新版本的 Tailscale

Tailscale 提供了 最新版本的 spk 給 Synology，使用者可以手動安裝或使用以下腳本自動化操作。

#!/bin/bash

# 更新 Tailscale
tailscale update --yes

# 檢查更新是否成功
if [ $? -eq 0 ]; then
echo "執行 Tailscale 更新成功"
exit 0
fi

# 若找不到指令，手動下載指定版本的 Tailscale 安裝包
url="https://pkgs.tailscale.com/stable/tailscale-x86_64-1.82.5-700082005-dsm7.spk"
filename=$(basename "$url")

# 在使用者的家目錄下建立暫存資料夾
cd ~
mkdir tmp_synology
cd tmp_synology

# 下載 Tailscale 安裝包
wget "$url"

# 安裝 Tailscale Synology 套件
sudo synopkg install "$filename"

# 啟動 Tailscale Synology 套件
sudo synopkg start Tailscale

# 移除暫存資料夾
rm -rf ~/tmp_synology

# 再次執行 Tailscale 更新
tailscale update --yes

修改腳本中的 URL

  1. 到 Synology 和 SynoCommunity 套件架構 確定你的 NAS 架構。
    • 例如：
      • DS220+ 架構為 x86_64。
      • DS218play 架構為 armv7。
  2. 到 Tailscale 釋出穩定版本。
  3. 找到與 NAS 對應的 DSM 版本及架構相符的 .spk 檔案，複製其 URL。
  4. 將腳本中的 url 變數替換為選定的 .spk URL。

注意： 如果 NAS 使用 x86_64 架構，則無需更改腳本。例如：DS224+、DS923+、DS723+、DS423+、DS1621+、DS220+、DS420+、RS820+、RS1219+、FS1018 和 FS3017 等型號均為 x86_64，可以直接使用腳本。

進入任務排程表

  • 點選左上角的主選單按鈕。

  • 選擇 控制台。

  • 點選任務排程表。

新增排程任務

  • 新增 → 排程任務 → 使用者定義指令碼

設定並儲存任務

  1. 設定任務名稱，並選 root 使用者執行。

  1. 設定腳本定時執行時間，在此設定每天凌晨 0 點執行此腳本。

  1. 在任務設定中，貼上為 NAS 架構調整過的腳本。可選擇設定任務執行結果發送至電子郵件。

  1. 點選 確認 儲存任務。若出現警告訊息，選擇 是 繼續操作。

手動執行任務

第一次可以手動跑一次任務，看 Tailscale 有沒有升級到最新版本：

  1. 在 任務計畫 中，右鍵點選剛新增的任務。
  2. 從右鍵選單中選擇 執行。

驗證更新

  1. 打開 套件中心，找到已安裝的 Tailscale 套件。
  2. 確認版本與最新發布的版本相符（如 2024-01-25 的 1.58.2），版本高於 Synology 官方版本 (1.38.4)。

注意： 此腳本可直接升級現有的套件中心版本（如從 1.38 升級），無需移除先前安裝的版本。

結論

安裝完成後，進入控制台並開啟 Tailscale 應用程式。此時會打開新的分頁，登入後就可以開始建立連線了。

詳細的連線設定可參考使用 Tailscale 輕鬆建立安全且私密的隧道。
