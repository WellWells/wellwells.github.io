前言

YouTube 上什麼類型的影片都有，搞笑片、知識分享、學習資源、政治討論。這些影片可能因為語言、說話語速、解釋方式或內容，看完不見得能完全理解，也不見得歸納得出結論。這時候可以把字幕丟給 ChatGPT 這類大型語言模型分析、統整，省下很多時間。

YouTube 字幕快速複製

要快速複製 YouTube 字幕，可以使用以下腳本。

在 YouTube 頁面載入後，當使用者未選取任何文字時按下 Ctrl + c 鍵，該腳本便會觸發，嘗試尋找並點選「顯示轉錄稿（Show transcript）」按鈕。當字幕表出現後，腳本會自動將其複製到剪貼簿，並在網頁右下方顯示通知。

其中：

  1. GPT_PROMPT 可以自訂，例如輸出為表格、使用條列式總結、提供詳細的解釋、使用其他語言進行說明等。
  2. COPY_NOTIFICATION_TEXT 為複製成功後，右下方顯示的提示文字。

該腳本僅適用於有在 YouTube 中建立或匯入字幕檔的影片。如果影片字幕是內嵌於影片中，則此腳本無法取得字幕檔，無法複製。

(function() {
    'use strict';

    const GPT_PROMPT = '使用"正體中文"，幫我消化時間軸後，我不需要知道詳細的時間，其中，如果影片有比較，請幫我列為表格，如果有方法，請幫我以條列式列出方法，請將影片的字幕檔轉換為詳細描述影片的重點與內容:';
    const COPY_NOTIFICATION_TEXT = '已複製';

    const copyToClipboard = text => {
        navigator.clipboard.writeText(text + "\n" + GPT_PROMPT).then(showCopyNotification);
    };

    const showCopyNotification = () => {
        const notification = document.createElement('div');
        notification.innerText = COPY_NOTIFICATION_TEXT;
        Object.assign(notification.style, {
            'font-size': '2em',
            position: 'fixed',
            bottom: '20px', right: '20px', padding: '10px',
            backgroundColor: 'rgba(0, 0, 0, 0.7)',
            color: 'white',
            borderRadius: '5px',
            zIndex: '1000'
        });
        document.body.appendChild(notification);
        setTimeout(() => document.body.removeChild(notification), 1500);
    };

    document.addEventListener('keydown', e => {
        if (!(e.ctrlKey && e.key === 'c') || window.getSelection().toString()) return; // Detect if Ctrl + C is pressed and no text is selected.
        e.preventDefault();

        const segmentsContainer = document.querySelector('#segments-container');
        const transcriptButton = document.querySelector('ytd-video-description-transcript-section-renderer button');

        if (segmentsContainer) {
            copyToClipboard(segmentsContainer.innerText);
        } else if (transcriptButton) {
            transcriptButton.click();
            setTimeout(() => {
                const newSegmentsContainer = document.querySelector('#segments-container');
                if (newSegmentsContainer) copyToClipboard(newSegmentsContainer.innerText);
            }, 1000);
        }
    });
})();

安裝腳本

  1. 安裝竄改猴 (Tampermonkey)

    要安裝腳本，先確認瀏覽器裡已經裝好 竄改猴 (Tampermonkey)。官方網站首頁下方就有 Chrome、Microsoft Edge、Firefox 和 Safari 的安裝方式。

  2. 安裝腳本

    安裝 Tampermonkey 後，可以前往 Greasy Fork 安裝 YouTube 字幕快速複製。

  3. 啟用使用者腳本

    Chrome 138 以前：需要在 chrome://extensions 右上方開啟「開發人員模式」全域開關，竄改猴才能執行使用者腳本。

    Chrome 138 起：Google 改為針對每個擴充功能個別控制。需前往該擴充功能的詳細資訊頁（chrome://extensions/?id=dhdgffkkebhmkfjojejmpbldmpobfkfo），開啟「允許使用者指令碼」開關，才能正常執行腳本。

    詳情可以參照 Tampermonkey 的官方教學

Greasy Fork 上還有許多其他網站的腳本。部分有害的網頁腳本可能會偷偷追蹤或竊取你的資料。

安裝之前，先看一下該腳本的安裝人數與最近的更新日期，判斷可不可靠。

第二部影片以 Mental Outlaw 頻道的 How SSH Works 為例子。可以得出 SSH 協定介紹影片的重點與內容：

影片概述

影片詳細介紹了 SSH（Secure Shell）協定的歷史背景、功能、技術細節以及應用場景。以下是影片的要點和內容。

影片要點

  • SSH 的發展歷史：

    • 1995 年，由 Tatu Ylonen 首次開發。
    • 起因於他發現有密碼嗅探器在芬蘭大學的網路上執行。

  • SSH 的功能和優勢：

    • 替代了 Telnet 和 rlogin 等不安全的連接方式。
    • Telnet 和 rlogin 的封包都是明文傳輸的，不安全。
    • 早期網路未發展成熟，多數連接仍在區域網路內部，安全風險相對較低。
    • 隨著網際網路發展，明文傳輸成為嚴重的安全問題。

  • SSH 的工作原理：

    • 資料加密：
      • SSH 加密傳輸資料，防止嗅探器窺探使用者名稱和密碼等敏感訊息。
      • 攻擊者可以看到資料被傳輸，但無法解讀內容。
    • 封包結構：
      • 包含封包長度（4 位元組）、填充大小（1 位元組）、有效載荷、實際填充和訊息鑑別碼（MAC）。
      • 填充為隨機位元組，增加嗅探難度。
      • MAC 驗證封包未被竄改。
    • 加密演算法：
      • 用戶端和伺服器之間協商選擇加密演算法。
      • 建議停用弱加密演算法。

  • SSH 的進階應用：

    • 多重連接：
      • SSH 支援多重連接和通道，如多個終端會話。
    • 圖形介面轉發：
      • 支援 X11 轉發，允許遠端執行圖形應用程式。
    • SSH 隧道：
      • 透過 SSH 隧道加密不安全的連接。
      • 可連接防火牆後的服務。

方法條列式

  1. 替代不安全的連接方式：SSH 替代 Telnet 和 rlogin，提供加密的安全連接。
  2. 加密資料傳輸：使用 SSH 加密封包，保護敏感訊息不被嗅探。
  3. 多重連接支援：SSH 允許多個終端會話和多重通道同時執行。
  4. 圖形介面轉發：使用 X11 轉發遠端執行圖形應用程式。
  5. SSH 隧道：透過 SSH 隧道加密和隱藏不安全的連接。

影片詳細描述

SSH 協定於 1995 年由 Tatu Ylonen 開發，以應對在其大學網路上發現的密碼嗅探器問題。SSH 的全稱是 Secure Shell，它用於取代早期的 Telnet 和 rlogin 等不安全的協定。這些協定的封包是明文傳輸，容易被嗅探和截取。隨著網際網路的發展，明文傳輸的安全風險顯著增加。

SSH 透過加密資料傳輸來解決這個問題，即使有人嗅探封包，也無法解讀其中的敏感訊息。SSH 封包的結構包括封包長度、填充大小、有效載荷、實際填充和訊息鑑別碼（MAC）。其中，填充是隨機位元組，增加了嗅探的難度。MAC 則用於驗證封包未被竄改。

SSH 支援多重連接和通道，允許使用者同時開啟多個終端會話。它還支援 X11 轉發，允許使用者在遠端執行圖形應用程式。此外，SSH 隧道可以加密和隱藏不安全的連接，並連接防火牆後的服務。

總之，SSH 提供了一個安全、靈活的遠端連接方式，廣泛應用於現代網路管理和資料保護中。

結論

裝好 YouTube 字幕快速複製腳本後，只需打開影片後按下快速鍵即可複製影片字幕，並將其貼至 GPT 進行分析。這樣就能在很短的時間內掌握影片的重點和結論，甚至整理出比較表格。不過影片本來的目的，是把枯燥的文字變成生動的內容，不是只給一段文字說明；視覺化的呈現能傳達更多訊息，看起來的體驗也更豐富。

我用這個腳本，多半是遇到語言障礙（對我來說是非英文或中文的影片），或影片內容真的不好懂的時候。我想，對於某個喜愛的創作者來說，影片製作得生動有趣，即使要花費 1 個小時的觀看也是願意的。
