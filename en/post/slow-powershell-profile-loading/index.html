Methods to Accelerate PowerShell Profile Loading Speed

PowerShell took two seconds to open, and the cause was the antivirus scanning scripts. How I confirmed the profile was to blame, which module paths to add to the Bitdefender exception list, and why posh-git stays slow anyway.

Introduction

After installing PowerShell, it is common to add extra extensions such as:

  1. PSFzf: Fuzzy search.
  2. zoxide: Quick navigation of the file system.
  3. posh-git: Git command prompts and autocompletion.
  4. Oh My Posh: Better PowerShell prompt styles.
  5. And more...

These plugins can be integrated into PowerShell as per their installation methods.

But they pile up and slow loading down, so every PowerShell startup takes a while.

This article will detail and document my process of solving this issue.

Identifying the Problem

First, in PowerShell, enter the following command to edit the user profile:

1
2

# If VS Code is not installed, use notepad.
code $PROFILE

Currently, the profile loads PSFzf and zoxide modules as shown below.

1
2
3
4
5
6

Set-PsFzfOption -PSReadlineChordProvider 'Ctrl+t' -PSReadlineChordReverseHistory 'Ctrl+r'
Set-PSReadLineKeyHandler -Key Tab -ScriptBlock { Invoke-FzfTabCompletion }

Invoke-Expression (& { (zoxide init powershell | Out-String) })

function grep { $input | out-string -stream | select-string $args }

Opening PowerShell shows a load time of approximately 2000 milliseconds. Run pwsh --noProfile to temporarily skip the profile and check whether the profile is what causes the delay.

1
2
3
4
5

PowerShell 7.4.3
Loading personal and system profiles took 2074ms.

PS C:\Users\Wells> pwsh --noProfile
PS C:\Users\Wells>

You will notice the load time is faster, indicating that the profile loading is indeed the issue.

Referencing PowerShell's official issue, others have experienced similar problems, which were resolved by disabling antivirus software.

Antivirus Impact

I use Bitdefender, which has a Scan scripts function. Disabling this function restored normal load times. I also turned off Bitdefender Shield entirely as a test, and load times improved the same way.

Solution

Adding trusted script locations to the exception list is enough. Search with the Everything tool for keywords like psfzf or zoxide to find paths such as:

1
2

c:\users\<user>\documents\powershell\modules
c:\users\<user>\appdata\local\microsoft\winget\packages\ajeetdsouza.zoxide_microsoft.winget.source_8wekyb3d8bbwe

Adding these paths to Bitdefender's exception list should reduce load times to under 500 milliseconds when opening a new PowerShell window.

But modules like posh-git are inherently slow to load. Disabling the antivirus does not change that, so adding them to the exception list will not help either.
