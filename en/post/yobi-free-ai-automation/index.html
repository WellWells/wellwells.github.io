Yobi: AI Automation That Drives ChatGPT & Gemini Through Their Web Interfaces to Build Your Own Agent

Yobi is an open-source AI automation app for Windows and macOS. It drives the web interfaces of ChatGPT, Gemini, Perplexity, and Duck.ai in a built-in browser window, and turns daily tasks into your own AI agent with its no-code flows.

Why Building Your Own AI Agent Is So Hard

Say you want a little helper that fetches the latest from a fixed handful of websites every day and pulls it into a single summary for you. Even for a chore this small—fixed sources, on a schedule—the mainstream way to build your own AI Agent goes roughly like this: get a computer, install something like OpenClaw, and follow a long tutorial through a series of setup steps. Just getting the environment up and running, on top of a dense wall of details, already trips up a lot of people.

Then you have to pick a model, and whichever route you take has its own barrier.

Going local: the model weights have to fit entirely into memory to run (on a typical PC it's mostly your GPU's VRAM; on Apple Silicon that's unified memory). Entry level is roughly 12–16GB to run 7B–14B small models. But models that size have clear weaknesses: weaker answers, more mistakes, and they often can't keep up with anything complex. For something genuinely usable you generally need a 30B-class model, whose Q4-quantized weights alone run 22–24GB, which works out to 24–32GB of memory or more. That means buying a not-cheap machine first.

Going cloud: from the start, you have to add a credit card and start counting token usage.

So it becomes: before I've actually done anything, just the getting-ready step already means either spending money on hardware or getting billed the moment I add a card. That barrier alone, I think, makes a lot of people give up.

On top of that, the tutorials for these tools are mostly in English. The web looks full of them, but very few setups keep running reliably over time. It's common to get halfway through and find the versions don't match, or the service was shut down ages ago.

What's worse, the whole AI ecosystem iterates so fast that packages update every other day, and just keeping up with the upgrades is tiring on its own. The flip side of fast iteration is that security risk comes with it: these projects, along with their long chain of dependencies, regularly turn up CVE vulnerabilities. Self-hosting an agent means chasing new features and patching security holes at the same time, and the long-term maintenance cost is far higher than it first looks.

Most of What We Do Is Just a Fixed Workflow

But think about it: a lot of what we do on a computer every day is actually a fixed set of steps, the kind of thing you could line up in advance, like Shortcuts on iOS.

Lock down the mechanical parts of a flow (fetching data, moving files, sending messages) as fixed steps, and only hand the small part that genuinely needs understanding or judgment to an LLM. That buys you two things: the whole thing runs faster, and token usage drops a lot, because you're not asking the AI to figure out everything from scratch, just calling on it at the key moments.

There's also a more important property this buys you: predictability. If you let the AI decide every step from start to finish, the results tend to be unstable. It does it one way today and another way tomorrow. But put the LLM inside a fixed flow you've laid out in advance, where it only handles the one bounded judgment you've assigned it and the inputs and outputs around it stay under your control, and the result comes out consistent every time.

That's the direction Yobi is built in. The goal is to let you spin up your own simple AI Agent with the least effort possible, and hand off the small, repetitive, fixed tasks in your day to it.

What Is Yobi

Yobi is a local-first, open-source (MIT) AI automation desktop app for Windows and macOS.

The way it works is simple. Yobi has a built-in browser window, opens up the web pages for ChatGPT, Gemini, Perplexity, and Duck.ai, types your prompt into the page, and reads the response back, the same way you'd use the site yourself. It doesn't call the providers' official APIs, and it doesn't run any AI model on your machine. For the ones that need an account, it reuses the session you're already logged into in your browser; some, like Gemini and Duck.ai, work out of the box with no login at all. (If you happen to have an API key already, there's an optional BYOK mode in settings that will use it, but that's a side option. The browser is still the default.)

Because it goes through each provider's own web page rather than a paid API, there's no API key to set up and no card to add, and it skips the hardware barrier of running a local model, too.

Open Yobi and you get a chat window like most other AI services, so pick a provider, type, and you're chatting.

Automating these web interfaces is against the providers' terms of service. Yobi doesn't bypass any technical protections: no CAPTCHA solving, no rate-limit evasion, and no IP rotation. With normal, light personal use, the most you're likely to hit is the occasional "verify you are human" prompt that you clear by hand. Heavy or abusive automation is what tends to get blocked. Use Yobi responsibly, and don't use it for anything illegal.

It's built for your own computer. The machine you work on, or a home PC that stays on 24/7, is a great fit for leaving it running, and it's all GUI, no command line at any point.

Download and Install Yobi

Windows: installing from the Microsoft Store is the easiest route. It updates itself and won't trip the unsigned-app warning. If you'd rather install by hand, the Releases page has an x64 installer. It isn't code-signed yet, so Windows throws up a protection screen the first time: click More info → Run anyway to continue.

macOS: grab the .dmg from Releases, the one with arm64 in its name for M1/M2/M3/M4 chips, x64 for Intel. Not sure which Mac you have? Click the Apple menu (top-left) → About This Mac and look at the Chip / Processor line. Open the .dmg and drag Yobi into your Applications folder. That's it installed.

macOS blocking it on first launch is normal. The app isn't signed with Apple's (paid) certificate yet, so the first time you open it macOS says "can't be opened because it is from an unidentified developer." It's not malware—it's just Apple's default guard. Pick one way around it:

  • Easier: double-click Yobi once (it gets blocked), then go to System Settings → Privacy & Security, scroll down to the blocked Yobi, and click Open Anyway.
  • One-and-done (if you're comfortable with the terminal): open Terminal, paste this line and press Enter (it'll ask for your login password—it's normal that nothing appears as you type):
1

sudo xattr -rd com.apple.quarantine /Applications/Yobi.app

Most people just need the prebuilt package. No need to build it yourself. If you want to tinker with the source or run the latest dev build, the GitHub project page has full build instructions.

Install it, open it, and you can start chatting right away. Let's walk through the basic features most people use day to day first, then move on to the more advanced Telegram integration.

Yobi's Everyday Features

Send selected text to AI with one key

This is Yobi's core. Select some text in any app → press Alt+G → it's auto-sent into the chat window → the response is saved straight to a timestamped Markdown file, without you lifting a finger. Translating, summarizing, rewriting, drafting a commit message. These "give it a chunk of text, get a chunk back" chores are exactly what it's for.

Tip: to keep the hotkey responsive at all times, let Yobi sit in the background via Settings → General → System Tray. If you don't like Alt+G, change it in Settings → General → Hotkey (the macOS default is Command+G).

Switch between providers anytime

All four providers are in the same window. Whichever one is better at a given kind of question, just switch to it, no need to keep a pile of tabs open.

Responses auto-save to Markdown

Every response is automatically saved as Markdown with a timestamp. No more "that answer was great, but I closed the window and now it's gone." (Markdown is a plain-text note format with the .md extension. You can open it in Notepad. The files are saved in Yobi's folder by default, and you can view or change the path in settings.)

And for the times you'd rather leave no trace, Ctrl+Shift+I switches to temporary chat mode, where replies are never written to disk.

Export as an image or PDF

Want to share a response or save it as something nicer? Export it directly as PNG, WebP, or PDF. Gradient palette, layout direction, whether to show the original prompt, the provider name, and the timestamp: all adjustable.

Customize tone and prompt preferences

Tacking "please answer in Traditional Chinese and keep it brief" onto every question gets tiring, so Yobi makes it a setting: tone (Default / Professional / Casual / Direct), length (Auto / Concise / Detailed), and a block of custom instructions prepended to every prompt automatically. You can also save your go-to phrasings as reusable templates.

Flows: Chain Fixed Steps Into Your Own Little Agent

Everything above is press-once, do-one-thing. A flow chains several steps into something that runs itself to the end: just like the iOS Shortcuts idea from earlier, no coding, just drag-and-drop. This is the core of how Yobi lets you build your own Agent.

A flow has three parts: when it triggers, what it does in between, and where the result goes.

There are five triggers, and one flow can use several at once:

TriggerDescription
⌨️ HotkeyA dedicated global shortcut for this flow
⏰ ScheduledRuns daily / weekly. Set the time and it fires automatically
🤖 Bot commandA custom Telegram or LINE command, e.g. /news <keyword>
💬 Chat commandType /your-command right in Yobi's chat box
👆 ManualPress run yourself whenever you need it

There are 44 skills to use in between, with more being added. Roughly, they fall into these groups:

GroupWhat it covers
📥 Pull dataWeb pages, RSS, HTTP APIs, YouTube transcripts, even live stock / forex / weather, no key needed
🌐 Drive a browserOpen tabs, click, fill forms, take screenshots
🧠 Ask AIChatGPT, Gemini, Perplexity, Duck.ai, or your own API key via BYOK
📤 Send resultsTelegram or LINE, email, a file, or the clipboard
🛠️ Run anythingPrograms, JavaScript, shell commands, plus system and power controls
🔀 Control flowLoops, conditions, scheduling

Never built an automation before? You don't have to. Describe what you want in plain language, like "every weekday at 8am, summarize my RSS feed and send it to Telegram", and AI assembles the whole flow for you. Tweak any step afterwards.

Each step writes its result to a named variable, and later steps pull it in with {{variable_name}}. To take the classic example, chaining "fetch RSS → summarize with AI → push to Telegram" looks roughly like this:

RSS Feed    → a list of {title, link} for new articles → output: articles
Stop Flow   → end here if the list is empty
For each    → each item is called article

  LLM prompt → "Summarize this in three sentences: {{page}}" → output: summary

End Loop

Pair that flow with the Scheduled trigger and it becomes: every morning it fetches the tech news I subscribe to, summarizes it into three sentences with AI, and pushes it to the Telegram on my phone. I'm still asleep and the summary is already in my chat. The key part is that fetching and sending are all fixed steps, and the AI only handles the small summarize bit in the middle, so it runs fast, saves tokens, and gives you a stable result every day.

Don't want to start from an empty canvas? The template gallery has 12 ready-made flows to drop in: RSS summary pushes, web monitoring (watch a site for new content, analyze it with AI, then push it out), YouTube subscription digests (summarize new videos from the channels you follow, thumbnails included). Pick one and a setup wizard walks you through the fields it needs, so you're not digging through every step yourself. Flows can be exported as .json files to share, or imported from a file or URL.

Controlling Yobi Remotely with a Telegram or LINE Bot

Yobi hooks up to both Telegram and LINE, so even when you're away from your computer, you can tell it to do things from your phone. The two are equivalent: they share the same command settings, and a flow's bot triggers and push steps work across either. Telegram is the walkthrough below; for LINE, settings has a two-step webhook guide that gets you there.

Roughly three steps:

  1. Get a Bot Token: search for @BotFather on Telegram and start it, tap Open to begin the chat, pick Create a New Bot, and follow the prompt to enter a bot name. It's straightforward and you'll be done in under three minutes, and at the end it hands you a Bot Token (i.e. an API key). If you'd rather watch it done, this video walks through the whole thing: How To Create A Telegram Bot In Python For Beginners (the bot-creation and token part near the start is all you need—you can skip the Python code after).

  1. Paste the token and enable it: go to Settings → Bots, paste the token into the Telegram Bot field, and hit Update Token. Once it's enabled, the Runtime Status below turns a green Running, meaning the bot is live.
  2. Generate a pairing code and invite the people you trust: in the Pairing section on the same page, hit Generate Code to get a pairing code and hand it to someone you trust. They DM your bot on Telegram and send /start <code> (or just tap the pairing link) to finish pairing. Only paired people can drive the bot, so you can safely share it with family or coworkers to use together.

Once paired, these built-in commands are available anytime:

CommandDescription
/gpt, /gemini, /pplx, /duck + a promptSend it to that provider (command names are yours to change)
/output <mode>Set the reply format (md / png / webp / pdf)
/statusCheck the current status
/restartRestart Yobi

Out with only your phone? Sending /gpt translate this into Japanese is all it takes. And if you'd rather not type commands at all, you can set it up so plain messages get answered as they come.

Hooking a bot up to an AI so it answers one message at a time is handy, but it's really closer to moving the chat onto your phone, not quite an agent yet. What gives it the shape of one is pairing it with the Bot command trigger from earlier: the same message can kick off a whole pre-arranged flow that fetches, decides, and outputs in one go. Getting a task actually carried out from start to finish. That's the part Yobi is really after.

Settings and Privacy

A quick pass over settings, mostly options to make it more comfortable: themes (including one that follows your system's light/dark mode), reading layout, response timeout, launch at startup, minimize to tray on close, Markdown zoom, and separate notification toggles for completion, success, and failure. Settings and data can be backed up in full and restored on another machine, and the interface supports 9 languages.

There's also a usage page with run counts, success rate, and a 14-day trend chart, all computed locally, so you can see at a glance whether your flows are actually running clean.

Two more are worth calling out. Email (SMTP) lets a flow mail its results straight to you, since not everyone wants everything landing in Telegram or LINE. And BYOK: if you already hold an OpenAI-compatible key (OpenAI, OpenRouter, Together, Groq, a local server—they all count) or a Gemini key, you can add it as an extra provider and pick it in chat and in flows like any other. The browser stays the default; this is just one more option.

On privacy, the key points: Yobi does no telemetry and collects none of your usage behavior, and all automation logic and stats run on your own machine. Your bot tokens, SMTP password, and BYOK keys are handed to the OS's built-in encrypted vault (Credential Manager on Windows, Keychain on macOS) and encrypted before being written to disk. What you ask the AI goes to the relevant provider and is subject to each one's privacy policy, and those platforms are outside the author's control. The whole project is open source, so all the logic is right there on GitHub for you to check.

Conclusion

The whole reason I made Yobi was to lower the barrier to building your own AI Agent as much as possible. No dropping a pile of money on a machine that can run a big model, and no adding a card to get billed from day one: just connect the web interfaces you're already logged into, line up your fixed steps as a flow, and the small chores in your day can run themselves. And because the AI is only called inside a fixed flow, the result is predictable. It won't work fine today and suddenly go sideways tomorrow.

Yobi isn't trying to replace full platforms like OpenClaw or n8n either. What it's after is letting you get simple automation plus an LLM working with the resources you already have.

If you come up with other applications, or have any suggestions for Yobi, you're welcome to open an Issue on GitHub and discuss it. If you want to tinker or are curious what it's built on, the source is all there too.

And if Yobi helps you out and you'd like to support me in keeping it going, you can buy me a coffee on the sponsor page, or just drop a ⭐ on the project on GitHub. Both help more people find it, and keep me motivated to keep it updated.
