Introduction

YouTube carries every kind of video: comedy, knowledge sharing, educational resources, political discussions. Language barriers, speech rate, explanation style, and how dense the content is can all make a video hard to follow fully, or hard to draw a conclusion from. In those cases you can hand the subtitles to a large language model like ChatGPT to analyze and summarize, which saves a lot of time.

Quick Copy YouTube Subtitles

To copy YouTube subtitles quickly, use the script below.

After a YouTube page has loaded, pressing Ctrl + C without any text selected will trigger the script. It attempts to find and click the Show transcript button. Once the subtitle transcript appears, the script automatically copies it to the clipboard and displays a notification in the bottom-right corner of the webpage.

Details include:

  1. GPT_PROMPT can be customized, for example, to output as a table, use bullet points for summarization, provide detailed explanations, or explain in another language.
  2. COPY_NOTIFICATION_TEXT is the message displayed in the bottom-right corner after successful copying.

This script is only applicable to videos on YouTube that have either created or imported subtitle files. If the subtitles are embedded within the video itself, this script cannot access or copy them.

(function() {
    'use strict';

    const GPT_PROMPT = 'Use "Traditional Chinese" to digest the timeline for me, I do not need to know the detailed time. If there are comparisons in the video, please list them as a table. If there are methods, please list them in bullet points. Please convert the subtitle file into a detailed description of the main points and content of the video:';
    const COPY_NOTIFICATION_TEXT = 'Copied';

    const copyToClipboard = text => {
        navigator.clipboard.writeText(text + "\n" + GPT_PROMPT).then(showCopyNotification);
    };

    const showCopyNotification = () => {
        const notification = document.createElement('div');
        notification.innerText = COPY_NOTIFICATION_TEXT;
        Object.assign(notification.style, {
            'font-size': '2em',
            position: 'fixed',
            bottom: '20px', right: '20px', padding: '10px',
            backgroundColor: 'rgba(0, 0, 0, 0.7)',
            color: 'white',
            borderRadius: '5px',
            zIndex: '1000'
        });
        document.body.appendChild(notification);
        setTimeout(() => document.body.removeChild(notification), 1500);
    };

    document.addEventListener('keydown', e => {
        if (!(e.ctrlKey && e.key === 'c') || window.getSelection().toString()) return; // Detect if Ctrl + C is pressed and no text is selected.
        e.preventDefault();

        const segmentsContainer = document.querySelector('#segments-container');
        const transcriptButton = document.querySelector('ytd-video-description-transcript-section-renderer button');

        if (segmentsContainer) {
            copyToClipboard(segmentsContainer.innerText);
        } else if (transcriptButton) {
            transcriptButton.click();
            setTimeout(() => {
                const newSegmentsContainer = document.querySelector('#segments-container');
                if (newSegmentsContainer) copyToClipboard(newSegmentsContainer.innerText);
            }, 1000);
        }
    });
})();

Installing the Script

  1. Install Tampermonkey

    To use this script, first install Tampermonkey in your browser. The bottom of the official homepage has installation instructions for Chrome, Microsoft Edge, Firefox, and Safari.

  2. Install the Script

    Once Tampermonkey is installed, visit Greasy Fork to install Quick Copy YouTube Subtitles.

  3. Enable User Scripts

    Before Chrome 138: Open chrome://extensions and enable the global "Developer mode" toggle in the top-right corner so Tampermonkey can run user scripts.

    Chrome 138 and later: Google switched to a per-extension toggle. Go to the extension's detail page (chrome://extensions/?id=dhdgffkkebhmkfjojejmpbldmpobfkfo) and turn on Allow User Scripts.

    For more information, see Tampermonkey's official tutorial.

Greasy Fork also hosts scripts for plenty of other sites, and some malicious ones quietly track or steal your data. Before installing any script, check its install count and the date of the most recent update to judge whether it's trustworthy.

Video Overview

The video details the history, functions, technical details, and application scenarios of the SSH (Secure Shell) protocol. Below are the key points and content of the video.

Key Points of the Video

  • Development History of SSH:

    • Developed by Tatu Ylonen in 1995.
    • Originated from discovering a password sniffer running on the Finnish university network.

  • Functions and Advantages of SSH:

    • Replaces insecure connection methods such as Telnet and rlogin.
    • Telnet and rlogin transmit data packets in plain text, which is insecure.
    • Early networks were not well developed, with most connections still within local networks, posing relatively low security risks.
    • With the development of the internet, plain text transmission became a serious security issue.

  • Working Principle of SSH:

    • Data Encryption:
      • SSH encrypts data transmission to prevent sniffers from spying on sensitive information such as usernames and passwords.
      • Attackers can see the data being transmitted but cannot read the content.
    • Data Packet Structure:
      • Includes data packet length (4 bytes), padding size (1 byte), payload, actual padding, and message authentication code (MAC).
      • Padding consists of random bytes to increase the difficulty of sniffing.
      • MAC verifies that the data packet has not been tampered with.
    • Encryption Algorithms:
      • Clients and servers negotiate to choose encryption algorithms.
      • It is recommended to disable weak encryption algorithms.

  • Advanced Applications of SSH:

    • Multiple Connections:
      • SSH supports multiple connections and channels, such as multiple terminal sessions.
    • Graphical Interface Forwarding:
      • Supports X11 forwarding, allowing remote graphical applications.
    • SSH Tunnels:
      • Encrypts insecure connections through SSH tunnels.
      • Can connect to services behind firewalls.

Methods in Bullet Points

  1. Replace insecure connection methods: SSH replaces Telnet and rlogin, providing secure encrypted connections.
  2. Encrypt data transmission: Use SSH to encrypt data packets, protecting sensitive information from being sniffed.
  3. Support multiple connections: SSH allows multiple terminal sessions and channels to run simultaneously.
  4. Graphical interface forwarding: Use X11 forwarding to run graphical applications remotely.
  5. SSH tunnels: Encrypt and hide insecure connections through SSH tunnels.

Detailed Description of the Video

The SSH protocol was developed in 1995 by Tatu Ylonen in response to the problem of password sniffers discovered on his university network. SSH stands for Secure Shell, and it was designed to replace earlier insecure protocols such as Telnet and rlogin. These protocols transmitted data packets in plaintext, making them vulnerable to sniffing and interception. As the internet evolved, the security risks associated with plaintext transmission significantly increased.

SSH addresses this issue by encrypting data transmissions, ensuring that even if data packets are sniffed, the sensitive information within cannot be deciphered. The structure of an SSH data packet includes packet length, padding size, payload, actual padding, and a Message Authentication Code (MAC). The padding consists of random bytes, increasing the difficulty of packet sniffing. The MAC is used to verify that the data packet has not been tampered with.

SSH supports multiple connections and channels, allowing users to open multiple terminal sessions simultaneously. It also supports X11 forwarding, enabling users to run graphical applications remotely. SSH tunneling can encrypt and conceal insecure connections, as well as connect to services behind firewalls.

In summary, SSH provides a secure and flexible remote connection method, widely used in modern network management and data protection.

Conclusion

Once the YouTube subtitles quick copy script is installed, just open the video and press the shortcut key to copy the subtitles, then paste them into GPT for analysis. That gets you the key points and conclusions of a video in very little time, comparison tables included. But the point of a video is to turn dry text into something lively, not to hand you another block of text. The visual presentation carries more than the words do, and it is a richer thing to watch.

I mostly reach for this script when there is a language barrier (for me, videos that aren't in English or Chinese), or when the content is genuinely hard to follow. For a creator I like, if the video is made lively and interesting, it's worth spending even an hour watching.
