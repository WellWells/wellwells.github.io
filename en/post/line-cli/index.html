Summarize LINE Group Chats in Claude Code and Codex with line-cli

line-cli lets Claude Code and Codex read your LINE for PC chats on Windows without a LINE bot, so they can summarize group chats and list unanswered questions.

I have one LINE group with Vendor A and another with Vendor B. Add a few projects and I'm in more than a dozen groups. When I open LINE in the morning, I want to know who I need to answer first. Yesterday Vendor A asked whether this revision of the drawing was ready to go to print, and that message was quickly buried under photos and a long run of "Got it" and "Thanks."

To get a quick read on a group without scrolling back through every message, I used to open each chat, select the messages, and paste them into Gemini or ChatGPT in the browser to sort out. By the time I'd pasted everything, I had already read through it all myself. So I wrote line-cli, a Windows command-line tool that reads and sends messages through the LINE account already signed in on the PC. It doesn't need a LINE bot or a webhook server. Now I tell my AI agent which groups to check, and it reads the conversations and lists the questions I haven't answered yet.

Ask Your AI Agent to Install line-cli

line-cli runs on 64-bit Windows 10 and 11. Before installing, sign in to LINE for PC on the computer at least once. Then open Claude Code, Codex, or Antigravity, whichever you normally use, and paste this into the chat:

1
2

Follow the installation instructions at https://github.com/WellWells/line-cli to install line-cli and its skill on this PC.
When it's done, tell me the version and which AI agents have the skill installed.

A skill is a set of instructions written for an AI agent. The installer adds it to the AI agents it detects on the PC. After installation, fully quit and reopen your AI agent so it loads the new skill. If you launch the agent from a terminal, open a new terminal window first.

Install line-cli with PowerShell

You can also install it yourself without an AI agent. Press Win + R to open the Run dialog, type powershell, and press Enter. You don't need to run it as an administrator. Paste this line into the PowerShell window and press Enter:

1

irm https://github.com/WellWells/line-cli/releases/latest/download/install.ps1 | iex

The installer downloads and verifies the files, then installs line-cli:

To choose the agents again: line skill install

On a first install, the installer ends with a firewall reminder. Sending messages and downloading files require a connection to LINE's servers, and update checks connect to GitHub. If your firewall blocks new programs by default, allow linecli.exe once. The line.exe on your PATH never connects, so it doesn't need a rule. Updates install to the same path, and the rule carries over.

The installer adds line to your user PATH, and the current PowerShell window can use it right away. Terminals and AI agents that were already open need to be restarted. With LINE running, run line chats once. line-cli retrieves the database key automatically on its first read, which takes a few seconds. line status only uses a key that has already been retrieved. line_running is true when LINE is running, and newest_message_at is the time of the newest message on this PC. If line_running is false, open LINE first. While LINE is closed, line-cli only sees messages up to the last sync. LINE just needs to run in the background, not with its main window open. After you close the window with the X in the top-right corner, LINE stays in the notification area at the bottom-right of the taskbar. Windows 11 may tuck it under the ^ hidden icons. Find Unanswered Questions in LINE Groups

For example, when I'm dealing with a lot of vendors, I first ask Claude Code to list the ones I've been in touch with recently:

Which vendors have I talked to recently on LINE?

Going by chat names alone, without reading any messages, the agent grouped the chats into official accounts, groups, and one-on-one chats, and listed the date of the last message in each. It then asked whether "vendors" should include service providers such as banks and clinics, and waited for my answer before reading those chats.

I told it to list suppliers only, then asked it to find this week's questions I hadn't answered yet:

Suppliers only. Go through this week's messages in these supplier groups, list the questions still waiting for my reply by supplier, and flag any deadlines they mentioned.

Only five supplier groups had new messages this week. The agent skipped the rest, since their last message predated this week. Under each group, it sorted items into decisions waiting on me, replies waiting on the supplier, and deadlines. It ended with two things to handle today. One was a supplier's question, addressed to me by name in the group, that I still hadn't answered. LINE has no "needs reply" marker. The agent made these calls after reading the conversations.

From there, I can ask the agent to analyze a supplier's questions and draft a reply, or have it send the reply to the group through line-cli. Before anything goes out, the agent shows the recipient and the full message and waits for my confirmation. When sending JPEG photos, line-cli removes the GPS location just as the LINE app does, without changing the original file on the PC.

Summarize Busy LINE Group Chats

A large group can get hundreds of messages a day, and I also ask the agent to summarize those. LINE's built-in Message Summary only works in OpenChat on the mobile app, not in regular groups or on the PC. Because line-cli reads the chat history from LINE for PC, it can summarize regular groups too. Here's an example with a public OpenChat about food in Greater Tainan. I typed this into Claude Code:

Analyze the recent messages in the Greater Tainan group on LINE.

After loading the line-cli skill, Claude Code ran five commands. It first counted 5,166 messages from November 10 to 26, around 300 a day. It then read about 200 messages from the morning of the 25th, plus messages from the whole period that mentioned recommendations. The posting stats showed that the top three members wrote about 40% of the messages. It also pointed out that the local data was only synced up to 1:02 PM on the 26th. LINE had newer messages that hadn't synced, and opening the group in LINE would fill the gap. line-cli can read OpenChat messages but can't post to OpenChat.

More LINE Tasks for Your AI Agent

line-cli reads, downloads, and sends LINE messages and files, and the AI agent handles the analysis and organizing. You can ask for any of these directly:

  • Back up the files I got on LINE last week to Google Drive.
  • Analyze the datasheet a vendor sent today and list anything that doesn't match our specs.
  • Pull together what my manager asked for on LINE this week and write it up as a full Word report.
  • Pick a good-morning image from my pictures folder and send it to Grandpa.
  • In the Family group's Notes, where are we having dinner this weekend?
  • Download all of this month's photos from the Family group's Album.
  • Mention Chih in the project group and ask how testing is going.
  • Unsend the message I just sent by mistake.
  • Let me know when Ming replies.

For Google Drive backups and Word reports, line-cli only downloads files and reads messages. Uploading and writing files depend on the AI agent's own tools, such as Google Drive for desktop installed on the PC. Before sending or unsending a message, or adding or deleting notes and photos, the agent asks you to confirm.

These are the same commands your AI agent runs when it reads and sends messages. They output JSON by default, and --text makes the output easier to read. The output below comes from my PC, with message content and IDs replaced.

When the number of results equals --limit, the note on the second line says there may be older messages. To read further back, add --until with the time of the first message. Messages from that same second appear twice.

Before sending, add --dry-run to preview the recipient and message. Nothing is sent at this step. A partial name won't work with --to. Use the full chat name or the chat_id from line chats:

Once it looks right, replace --dry-run with -y to send it. Other common commands:

TaskCommand

Run line help to see every command, and line read --help to look up the options for a single command.

Send AI Tasks from LINE on Your Phone with Yobi

line-cli works through an AI agent on your PC. When you're away from the computer, you can use Yobi, which I also wrote. Yobi has a built-in LINE (this PC) connector that reads and sends LINE messages the same way line-cli does. Turn it on under Settings › Connectors › LINE (this PC), and Yobi's agent can search and read your conversations in LINE for PC and send messages and files from your account.

To give Yobi tasks from LINE, also go to Settings › Bot Integrations › LINE PC and turn on the LINE PC bot. Then, from your phone, send a message that starts with Yobi in any group or one-on-one chat, such as Yobi, will it rain tomorrow?, and Yobi replies from your account with [Yobi] at the start. The first time someone else in a group calls Yobi, Yobi asks you to allow them. You don't need a LINE Official Account or a webhook, but the PC has to stay on with both Yobi and LINE for PC running. Yobi's flows can send their results to a LINE group or friend you choose, and the same agent can take tasks from Telegram, Discord, and Slack.
