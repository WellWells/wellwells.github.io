Why sign up for your own LLM API key

The mainstream tools for automating AI right now are OpenClaw and n8n, and both start the same way: sign up for a large language model (LLM) API key, then paste it into the tool's settings.

The key is an identifier: the server reads it to determine which account and project a call bills to. The limits come as three numbers: requests per minute, requests per day, and tokens per minute. A key also lets you pin the model version, so nothing gets swapped out silently, and every call returns usage figures and an error code that identifies the limit you hit. The web interface provides neither.

Yobi takes the other route, driving the AI services' web interfaces in a built-in browser window with no key and no card, which is enough most of the time. Two situations break it: a provider redesigns its page and the flow no longer matches what's on screen, or the web interface has to wait for a full page render before it can read the reply and falls behind a tight schedule. Both are solved by supplying your own key.

This post covers how to obtain free API keys from Gemini and OpenRouter, verify their quotas, and integrate them into Yobi, then rotate several keys through a key group for a few hundred calls a day at no cost. The same key can be configured in OpenClaw or n8n, and the specific fields are detailed later.

What a key lets you build

Tools like OpenClaw and n8n only need the key in a credential field; your own code can call the model directly, with curl on the command line or requests and the official SDK in Python. The official SDK is the fastest path: run pip install google-genai, store the key in the GEMINI_API_KEY environment variable, and five lines get you a response:

Save it as hello.py and run GEMINI_API_KEY=the key from AI Studio python hello.py — the model's reply prints within a few seconds.

I use Yobi for summarising: it checks RSS every ten minutes and pushes a few lines to my phone whenever a new article appears. I documented that flow in Automating RSS Digests with a Telegram Bot, which uses the keyless browser mode, and switching it to BYOK means changing one entry in the model menu.

Whether any of it is free depends on which provider issues the key.

Whose API keys are actually free

Plenty of services will issue an API key, but whether there is a free tier varies a lot. For OpenAI and Anthropic the API is a revenue line alongside the consumer web app and subscriptions: companies integrating a model into an internal system and third-party products packaging AI into their own features both pay per call. Neither pricing page carries a free plan, and Anthropic only mentions a small amount of trial credit for new accounts. Google is the opposite: Gemini has a standing free tier, with the quotas published on the AI Studio rate limit page, which this post checks directly.

Other providers follow a standard billing model: attach a card for pay-as-you-go billing, or buy prepaid credit. Prices are quoted per million tokens, input and output billed separately, with output typically three to five times the input rate. Every console lets you set a spending cap, so set one before your first call.

Official pricing as of September 2026, in USD per million tokens. There are hundreds of models available, and the table keeps the ones that can carry an agent, plus Gemini Flash Lite:

The Chinese labs price well under the American two: as a primary agent model, GLM 5.3 charges 4.40 on output and Kimi K3 charges 15.00, against 25.00 for Claude Opus 5. Cheap is not the same as free, though: Kimi requires a USD 1 payment even for Tier 0 before the API opens, so it has no free entry point.

"Free" in this post means one specific thing: you register an account and start calling, with no card and no prepaid credit. Three providers qualify, and their available models can be named exactly.

Gemini concentrates its free quota in the Flash line, and the Pro models cannot be called at all. On OpenRouter the free models are the ones whose id ends in :free, priced at USD 0 in and out and sharing one account-wide daily ceiling; two of the top ten on the usage leaderboard are (free) variants. Groq lets you create a key in the Console straight after signing up, with no payment details either.

Z.ai marks a handful of Flash models as free on its pricing page, but the docs don't say whether signup needs a card, and I have not signed up, so I cannot confirm it. Cerebras, SambaNova, and Fireworks offer trial credit that expires, and the Cerebras docs add that a verified payment method is required first, which makes it deferred payment rather than free.

Getting a Gemini API key

Sign in to Google AI Studio with a Google account, pick "API Keys" on the left, then "Create API key" at the top right.

Give the key a name you'll recognise later, leave the project dropdown on "Default Gemini Project", and select "Create key".

Once the key appears, the same window shows the project name and project number. Google now issues keys that start with AQ. rather than the old AIza, so a key that looks unfamiliar is not the wrong key.

The key window doesn't show a quota, and the official Rate Limits page no longer publishes the table. The quotas have to be read from AI Studio: pick "Rate Limit" on the left and enable "All models" at the top right. Every model's RPM, TPM, and RPD is then listed, with your current tier above the table.

Requests per minute (RPM) is the short-term throttle, requests per day (RPD) is the daily total, and tokens per minute (TPM) depends on the length of the text you send. A call that exceeds any one of them returns a 429.

Quotas apply per project rather than per key, so creating extra keys in the same project adds nothing.

Getting an OpenRouter API key

OpenRouter's pitch is the single key: sign up once and you can reach hundreds of models, switching between them by changing a model id instead of opening another account. Its free-model lineup is also the most complete.

Sign in at openrouter.ai/settings/keys and select "New Key" at the top right. Name it, leave Expiration on "No expiration" and Credit limit blank, then "Create".

The key is shown exactly once. The dialog states it plainly: You will not be able to see it again. Once closed, the list only shows the first and last few characters, so a key you failed to save has to be recreated.

Free models work without buying any credit. The official limit table is explicit: :free models run at 20 requests per minute, with 50 requests per day for accounts that have purchased under USD 10 of credit all-time, and 1,000 a day once that total is passed. The threshold is whether the credit was purchased, not whether it was spent, so that USD 10 stays in your balance and still pays for paid models later.

Check the list yourself rather than trusting a snapshot: open the model list and the page narrows to the :free variants. That filtering comes from variant=free in the URL, not from a price range. The Text tab across the top carries the current count, which read 18 when I looked, several of them with a context window of a million tokens.

That roster turns over fast: plenty of tutorials still name Llama 3.3 and Qwen3 Coder, while today's list is Nemotron, Ling, Inkling, and Laguna. Copying a model id out of an old tutorial returns an error.

None of the three requires a card, so what separates them is which limit you hit first. Groq allows twice as many calls a day as Gemini, but only 8K tokens a minute, so one long article consumes most of a minute's budget and a summarisation flow stalls there. With Gemini's 250K TPM, length is rarely a constraint.

For long-term use, Gemini Flash Lite is the practical pick: 500 calls a day, a model version you choose yourself, and room for long inputs. Pay later if you outgrow it, since attaching billing moves Gemini from the Free tier to Tier 1, where the quotas are orders of magnitude higher.

Wiring a key into Yobi

Yobi's "Bring Your Own Key (BYOK)" section is at the bottom of Settings → Model Sources, and "Add instance" opens a form.

"Provider" is a dropdown with the mainstream services already built in. Select one and the Base URL is filled in automatically, with no documentation to search through: Gemini uses https://generativelanguage.googleapis.com/v1beta/openai and OpenRouter https://openrouter.ai/api/v1. A paid key and a free key go in the same field.

A provider not on the list can still be used: scroll to the bottom for "OpenAI-compatible" and supply the Base URL and model id yourself. Any service exposing an OpenAI-compatible endpoint works.

Fill the form top to bottom:

  1. Name: this is what you'll see in the model menu later, so make it specific, like Gemini Flash Lite.
  2. Provider: pick "Gemini (Google)".
  3. API key: paste the string you just collected.
  4. Model: select "Load models" next to the field and Yobi retrieves the list of available models from the endpoint. Once loaded, typing filters it, so pick models/gemini-3.5-flash-lite. This is the one I run day to day, and 500 calls a day covers most of my needs at good speed.
  5. Select "Test", wait for "Connection OK — the model replied", then "Save".

Repeat the same steps for the OpenRouter key, choosing "OpenRouter" as the provider and a model whose id ends in :free.

Saved instances appear in a "Bring Your Own Key (BYOK)" group at the bottom of the model menu in the chat window, and in the LLM step of a flow. Browser mode remains the default, and BYOK only adds options.

Ask a BYOK instance something and the reply comes straight from the API with no browser window, and the token count for the exchange is shown under the title.

The same key in n8n and OpenClaw

Switching to another tool means filling in the same three fields: the endpoint, the model id, and the key. I have only read the docs for n8n and OpenClaw rather than running either one, so the field names below are compiled from those docs.

n8n ships credential types for both, so there's no URL to assemble. Gemini uses "Google Gemini(PaLM) API": paste the key and leave API Host on the default https://generativelanguage.googleapis.com, which the docs note cannot currently be pointed at a custom host or proxy. OpenRouter gets its own Chat Model node that is configured like the OpenAI one, with its ai_languageModel output feeding an AI Agent or a Basic LLM Chain.

OpenClaw takes its key in the Control UI under Settings → Models, which stores it at models.providers.<id>.apiKey in the config and marks whether each key came from the config or an environment variable without displaying the key itself. An environment variable also supplies it, GOOGLE_API_KEY for Gemini and OPENROUTER_API_KEY for OpenRouter, with the primary model set at agents.defaults.model.primary.

Storage is the part worth attention: Yobi keeps its keys encrypted on the machine, while config-file tools make it easy for a key to end up in version control. Keep it in an environment variable rather than hardcoded in a flow file.

Gemini and OpenRouter both expose OpenAI-compatible endpoints, so tools without a ready-made node can still be used as long as they allow a custom Base URL. Gemini's compatible endpoint is the one Yobi filled in earlier, https://generativelanguage.googleapis.com/v1beta/openai.

Stacking quota with a key group

Raising the real ceiling means spanning different providers, or different projects and accounts. If you already keep a work and a personal Google account, or already have keys under several projects, this section applies to you.

Yobi's "Key groups (rotation)" does exactly this. Under the BYOK card in Settings → Model Sources, select "Add group", name it, and tick the keys to rotate.

The group above, GeminiPod, holds seven keys. Once saved it appears in the model menu like any other instance, rotates to the next key on each request, and skips a key automatically when one fails. The keys must belong to separate projects or accounts for the quotas to add up.

A group raises two quotas at once: RPD and RPM. The second matters more for agents, since Gemini Flash Lite allows 15 RPM and an agent making several tool-call round trips inside a single task exhausts a minute's allowance quickly. Rotation spreads requests across every key in the group, so more requests go out in the same window, and a key that receives a 429 is replaced by the next one.

Free models are not always there

Testing OpenRouter produced three consecutive failures, and only the third model returned a reply:

  • nvidia/nemotron-3-ultra-550b-a55b:free returned Upstream error from Nvidia: Service temporarily overloaded. The big free models have the longest queue.
  • thinkingmachines/inkling:free returned HTTP 403, saying the model is only served to agentic apps on an approved list. Tools outside that list cannot call it.
  • google/gemma-4-31b-it:free returned HTTP 429, the day's quota already used.

The Gemini key answered on the first try in the same session. For a flow that has to run every day, Gemini Flash Lite is considerably more dependable than OpenRouter's free models. OpenRouter earns its place by letting one key reach hundreds of models, which is a different job.

Conclusion

Gemini 3.5 Flash Lite is the key I keep running, and it covers my Yobi summarisation flow, with the OpenRouter key in a key group as a spare. Moving either one to OpenClaw or n8n is the same three fields again, so changing tools doesn't mean signing up again.
