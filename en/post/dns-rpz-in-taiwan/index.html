Introduction

The scandal involving entertainer Mickey Huang has recently led to widespread news about the closure of "創意私房" Driven by curiosity, people who try to browse this content will find that the URL is hijacked to TWNIC's blocking page.

The Taiwan Network Information Center (TWNIC) is the organization responsible for managing Taiwan's domain names (.tw and .台灣) and IP addresses. It oversees the allocation of internet resources, promotes technical education, supports international cooperation, and advances network security development.

Internet Freedom

The internet itself is free, meaning you can connect to any URL. However, due to regulatory restrictions, governments may control or prohibit access to certain websites. Common examples include China's blockage of Google, YouTube, Facebook, Wikipedia, and others.

Internet freedom does not imply tolerance or encouragement of activities such as pornography, gambling, or piracy, especially when these activities are based on the suffering of others or infringe on others' rights. These behaviors should not be encouraged or allowed. Worse still, if someone commits a crime or engages in illegal activities due to watching such videos, it creates even bigger problems.

In Taiwan, as early as 2013, the Intellectual Property Office proposed that ISPs block websites providing infringing content via DNS or IP address blocking, but it went nowhere.

With the recent media coverage, clicking on Creative Private Room redirects to a blocking page. In fact, on 2020-03-30, TWNIC (Taiwan Network Information Center) held the first DNS RPZ meeting, and network blocking via DNS has continued since then.

DNS RPZ

What is DNS RPZ

Domain Name System Response Policy Zone (DNS RPZ) is a technology developed by the Internet Systems Consortium that provides a mechanism for URL filtering at the DNS server level.

RPZ lets network administrators add special response policy zones to DNS servers. When a query hits a domain name on the filter list, the DNS server returns a specified IP address or error message from that zone, redirecting or blocking the connection to the site. That keeps users off malicious websites, phishing sites, or politically incorrect content.

For example, if a computer wants to browse NSFW.com, which has a correct IP address of 1.2.3.4, and the DNS server used by the computer is from Chunghwa Telecom (168.95.1.1) and NSFW.com is on the filtering list, the DNS server will return NXDOMAIN (or be redirected to a specific IP address), making it impossible to connect and obtain the original webpage content.

If the DNS server is changed to a public DNS service not participating in RPZ filtering, such as CloudFlare's 1.1.1.1, the resolution of NSFW.com will not be affected by the filtering list, allowing normal access to the original content.

Is RPZ Secure?

The core of domain name resolution is turning a URL into its matching IP address. When a URL goes to a DNS server, the server only logs the domain name you requested; it never touches the page content or the sensitive data in transit (passwords, personal data, and so on). The DNS server returns a filtered or verified-safe IP address, so the connection stays relatively safe.

For example, when a user attempts to visit NSFW.com, if its domain name is hijacked and returns 150.242.101.120, the browser will compare the connection certificate. If the certificate does not match the expected domain or the connection uses the HTTP protocol, an insecure warning will be displayed. Should the user choose to ignore the warning, they will be redirected to the blocking page set up by TWNIC.

If a computer's "trusted root certificates" are tampered with, then even with a hijacked domain and a trusted suspicious certificate, the browser may not raise a useful warning. That lets an attacker run a man-in-the-middle attack (MITM), intercept and read all the web traffic, and block more precisely. So on a public computer, avoid logging in to sensitive accounts to cut the risk.

Related Applications

For related applications, users can set up their own DNS servers to filter out unwanted content such as ads, viruses, pornography, and phishing websites. A self-hosted DNS server functions similarly to RPZ. There are ready-made solutions available on the market, such as the free NextDNS or the open-source tool AdGuardHome that can be self-deployed.

How to Avoid Network Blocking

What was described above is really just one layer of RPZ applied during DNS resolution. To browse normally, don't use the DNS servers these organizations hand you by default. Newer systems can set DNS over HTTPS (DoH) to stop attackers from forging DNS messages. To a network administrator, DoH traffic looks the same as any other HTTPS traffic, which makes it harder to track which sites a user visits.

Mobile Devices

On mobile devices, most modern systems support DNS over HTTPS (DoH). On an iPhone, you enable it by installing a mobileconfig configuration file. Once it's installed, all the phone's traffic resolves through the DNS server you picked, and you can go with a recognized provider such as Google, Cloudflare, or Quad9.

  • Cloudflare 1.1.1.1
  • Cloudflare 1.1.1.1 Security
  • Google Public DNS
  • Quad9
  1. Click the link above and choose to allow the installation of the configuration profile.
  2. Navigate to "Settings" → "General" → "VPN & Device Management" in the system.
  3. In "Downloaded Profiles", locate the Cloudflare DNS over HTTPS profile and tap "Install" in the upper right corner.
  4. Enter the "DNS" settings and switch from "Automatic" to "Cloudflare DNS over HTTPS".

After these steps, your phone resolves domain names over DoH, which avoids DNS hijacking and adds a layer of privacy.

Note: Please note that DNS over HTTPS (DoH) is solely a technology for encrypting DNS queries and is not equivalent to a Virtual Private Network (VPN).

Conclusion

Internet censorship is a complex issue, a constant tug-of-war among governments, corporations, and users. In Mainland China, for instance, users risk breaking the law with VPNs paired with various encryption protocols (such as Shadowsocks, V2Ray, Trojan, Hysteria, Juicity, WireGuard, and Snell) to get around restrictions. Taiwan, on the other hand, is flooded with VPN services where a paid subscription is enough to bypass the block, and the only ones who profit are the VPN providers, relay operators, and VPS suppliers.

Once a piracy website like NSFW.com is blocked, the operator can simply switch to NSFW.ai or NSFW.io, making timely government intervention nearly impossible. Content is even shared and sold via Telegram, Line, Facebook, and various private groups, rendering blocking measures ineffective. As the media sensationalizes the "Chuangyi Private House has been closed" message, it inadvertently increases public awareness of the website.

The adult content industry encompasses a wide range of ethical and legal issues, yet as long as market demand persists, even massive financial investments cannot completely dismantle the industry. The true solution lies in offering substantial rewards to apprehend the masterminds behind the scenes (such as content creators or fraudulent advertisement distributors), along with enforcing strict legal penalties; for repeat offenders, comprehensive blocking measures should be adopted.

Still, whether the pornography industry can really be wiped out is doubtful: those determined to view such content will always find a way, even if it costs more. In 2021, Apple also proposed a Child Sexual Abuse Material (CSAM) detection system, which aimed to spot such material by comparing users' iCloud photos against known CSAM image hashes from child protection organizations. The plan was shelved over controversy and accuracy concerns.

I hope better measures come along in the future to cut down on videos filmed under coercion and the flood of worthless scam ads.
