Perfect Screenshot Techniques in Browsers

Outlines screenshot techniques for browsers, using developer tools and system shortcuts for captures, plus Netflix DRM workarounds and full-page imaging.

Introduction

Taking a screenshot used to mean hitting Print Screen to grab the whole screen, pasting it into PowerPoint or Paint to crop, then copying it out to share.

Windows 10 and later ship the Snipping Tool, which is far more convenient. Its shortcut is ⊞ Win + Shift + S, letting you capture any screen region and save the image straight to the clipboard. macOS also has built-in screenshot functionality, with a shortcut of Shift + Command + 4 for quick webpage screenshots.

However, built-in tools have limitations:

  1. They can't capture full-page screenshots of a webpage.
  2. On DRM-protected media like Netflix, the screenshot turns into a black screen.
  3. They don't allow flexible capture of web elements.

This article focuses on what the major browsers can already do on their own: no third-party extensions or programs, and you can still get past the limits above and grab a full page or a single element precisely.

Built-in Methods

Chrome

Google Chrome, the most popular browser, has relatively limited built-in screenshot functionality. The most convenient way is a system shortcut:

  • Windows: ⊞ Win + Shift + S
  • macOS: Shift + Command + 4

To capture a full page or a specific element, see the General Screenshot Methods.

Microsoft Edge

Since 2020, Microsoft Edge has been based on the Chromium engine, making it the default browser for Windows. With its shared rendering and JavaScript engines with Chrome, Edge offers similar efficiency, webpage compatibility, and support for modern web technologies.

Edge includes a built-in screenshot tool, reached by Right-click → Web Capture or the shortcut Ctrl + Shift + S. It captures either a selected area or the full page, and has basic annotation features. Once you're done, copy it to the clipboard or save it as a file.

Mozilla Firefox

Mozilla Firefox, developed by the non-profit Mozilla Foundation, is a well-established open-source browser. Despite using a different rendering engine than Chromium, resulting in slight differences in page loading speed and compatibility, performance is still stable. Though its market share has declined in recent years, its open-source nature and continued support from Mozilla ensure a loyal user base.

Firefox's built-in screenshot feature is fairly complete, with the same shortcut as Edge, Ctrl + Shift + S. Besides capturing a specific region of the screen, you can click an HTML element on the page and screenshot it directly. Like Edge, it offers Save Full Page or Save Visible Range.

Safari

Safari is the default browser on macOS, but like Chrome, it lacks a built-in right-click screenshot feature. Use the system shortcut for a region capture (Shift + Command + 4).

To capture a full page or a specific element, see the General Screenshot Methods.

General Screenshot Methods

Element Screenshot

The developer tools in every mainstream browser have a precise screenshot feature that captures a specific web element or an entire page. Follow these steps:

  1. In Chrome / Edge / Firefox / Safari, open Developer Tools with the shortcut F12 or Ctrl + Shift + I. You can also go to the top-right menu → More Tools → Developer Tools.
  1. Select the element picker, find the target element you want to capture, right-click, and select Capture node screenshot to take a precise screenshot of the object.

Full-Page Screenshot

To capture an entire webpage screenshot, open the Developer Tools, select the <html> or <body> element, right-click, and choose Capture node screenshot. This method works well on most pages, but for dynamically rendered websites, third-party tools may be required to simulate scrolling and stitch the images together.

Simulating Device Screenshots

The button next to the element picker is the Toggle Device Toolbar (Ctrl + Shift + M), which simulates different device screen sizes and user agents, so you can see how the page looks on each of them.

In device simulation mode, expand the top-right arrow to reach buttons for capturing either the visible area or the entire page. Those work for screenshots too.

How to Screenshot Netflix

Netflix and other streaming media use digital rights management (DRM) to protect video content, with Widevine handling decryption and rendering. Browsers enable hardware acceleration by default, which puts them on Widevine L1 protection and delegates decryption and rendering to hardware (like the GPU). L1 relies on a trusted execution environment (TEE), so screenshots and screen recordings come out as a black screen.

Disable hardware acceleration and the browser switches to software video decoding instead of handing it to the GPU. Software decoding cannot rely on a TEE the way hardware decoding does, so screenshots and recordings no longer come out black.

Chromium-based browsers all have a graphics acceleration toggle. Turn it off and the built-in screenshot method captures the picture.

With hardware acceleration still on, the Element Screenshot method doesn't help either. Run Capture node screenshot on the <video> node and you get the same black frame. It only becomes useful once hardware acceleration is off, where it captures the video itself without the player's control bar.

Conclusion

I use Edge day to day, so most of the time it's Ctrl + Shift + S, capture and share. For a full page or a specific element, I open the Developer Tools and right-click the object to capture the node screenshot. That's quicker than launching a dedicated screenshot app.
