How to Remap the Copilot Key to Ctrl Using PowerToys

New laptop replaced the right Ctrl with a Copilot key? Learn how to remap Copilot back to Ctrl using PowerToys Keyboard Manager in 5 easy steps.

Introduction

I recently got a new keyboard at home. Muscle memory kicked in and I reached for the right Ctrl key—and up popped a Microsoft Copilot window.

Most new Windows laptops and PCs now ship with a Copilot key as standard. If you're someone who habitually uses the right Ctrl with left-hand shortcuts, this change is nothing but a nuisance. Every time your fingers fire on autopilot, the Copilot panel crashes your flow.

Microsoft PowerToys puts it back. The whole setup takes under three minutes.

What Is the Copilot Key?

Microsoft officially announced the Copilot key at CES in January 2024, billing it as the most significant keyboard change in nearly 30 years, the biggest since the Windows key was introduced in 1994. Starting in early 2024, major brands like Dell, ASUS, Lenovo, and HP began shipping it on their new Windows 11 laptops, typically in the bottom-right corner, replacing the right Ctrl key.

Under the hood, the Copilot key doesn't send a unique signal. It registers as the keyboard shortcut Win + Shift + F23. Because of this, you need to remap a shortcut, not a key. Simply rebinding F23 alone won't work.

Remapping the Copilot Key with PowerToys

The most reliable solution is Microsoft PowerToys 0.98+ and its Keyboard Manager.

PowerToys is a free utility suite built by Microsoft. Beyond remapping shortcuts, it includes plenty of other handy tools.

If you haven't installed PowerToys yet, check out: Awesome Windows—Essential Productivity Software Installation and Guide.

Once it's installed, follow these five steps.

Step 1: Open PowerToys Settings

Find the PowerToys icon in the system tray at the bottom-right of your taskbar and double-click it to open Settings.

Step 2: Search for and Open Keyboard Manager

In the search bar at the top of the Settings window, type Keyboard, then select Keyboard Manager.

Step 3: Enable Keyboard Manager and Open the New Editor UI

On the Keyboard Manager page, make sure the feature is enabled.

Then, it's worth turning on Try the new editor: this is the redesigned Keyboard Manager UI introduced in PowerToys 0.98, and it's easier to work with.

With the new editor enabled, key remaps and shortcut remaps are managed in a single unified interface. Just click the editor button to access both. If you're on the older UI, scroll down to the Shortcuts section and click Remap a shortcut instead.

Step 4: Add a New Remap

In the shortcut remapping list, click the ＋ Add remapping button in the top-left corner.

Step 5: Configure the Mapping Rule

Set up the new mapping rule as follows:

FieldValue
Shortcut (trigger)Win (Left) + Shift (Left) + F23
Action (mapped to)Ctrl (Left)

When you're done, click Save.

💡 About "Allow chording": Chording is an advanced feature that lets you use a shortcut combination as a prefix, followed by a second key to trigger different actions, great for grouping related functions together. For example, from the official docs: Shift + Ctrl + V → U to increase volume, Shift + Ctrl + V → D to decrease it. In that scenario, Shift + Ctrl + V becomes the shared prefix for all volume controls. For our Ctrl remapping here, it makes no difference whether you enable it or not.

The change takes effect immediately. No reboot required.

Verifying It Works

Once configured, open any browser window and use the Copilot key to try Ctrl (Copilot Key) + + and Ctrl (Copilot Key) + -. If the page zooms in and out normally, the remap is working.

2Search "Keyboard," open Keyboard Manager

4Add a new shortcut remapping
5Set trigger to Win + Shift + F23, action to Ctrl (Left), then Save

Closing Thoughts

Takes less than three minutes to set up, but the interruptions it saves you add up. Microsoft's push to promote AI assistants makes sense from a business standpoint. Copilot on Windows is still genuinely clunky, though, and handing it a key as commonly used as Ctrl leaves me a little speechless. PowerToys is a Microsoft product itself, so fixing this with it is a compromise of sorts.

And this approach isn't just for the Copilot key. If you want to remap any key on your keyboard to a custom function, say turning Caps Lock into Ctrl or mapping a forgotten Scroll Lock key to media controls, PowerToys Keyboard Manager handles that too.
