什麼是 TWQR ?

TWQR 是由財金公司所推出，串聯銀行與電支機構兩大支付體系所推出的 QR Code 支付共通標準，解決市面上各種支付 QR Code 規格各異、無法互通，商店擺滿 QR Code 立牌讓民眾結帳時混淆不清的問題。

TWQR 掃碼贊助

如果您正在使用電腦瀏覽，請開啟 iPASS MONEY、街口支付、全支付 或 悠遊付 等行動支付 App 掃描下方 QR Code 進行贊助（請勿直接使用相機 App 掃描）。若您沒有上述 App，請參考下方「支援的行動支付 App」。

手機版用戶教學：

  1. 對此網頁的 QR Code 截圖。
  2. 開啟下方任一支援的行動支付 App。
  3. 點選 App 內的「掃描」或「付款」功能。
  4. 選擇「從相簿讀取圖片」並選取剛剛的截圖即可付款。
